# 歌词滑轨轻量预览验证

2026-10-01，本地 Windows / Electron 42。基线为提交 `5cf43bf`。

## 行为

鼠标、触屏和键盘连续调整期间，歌词使用基础纹理与单次采样的文字着色分支，保留原文、译文、颜色、进度和布局。发光、故障与粒子装饰暂停，高清纹理和离屏歌词预构建等待手势结束。原有高级纹理保留，字形确实改变时才替换基础纹理。

位置、大小、间距、透明度和故障参数直接更新；字重、字间距、边缘渐隐仅更新可见行的基础文字，每帧最多一次歌词纹理上传。松手先准备可见文字，再补装饰及高清纹理；旧文字保留到新文字就绪。新拖动或切歌使旧任务失效。

低效果状态只存在于运行时，不进入配置、预设或分享码。手势结束时保存参数，原有字段顺序和范围保持不变。

译文间距小于默认值时，按缓存的实际字形边界连续压缩；最小值 `0.28` 留出原文字号的 2% 空隙。默认值和更大的数值沿用原来的距离。

## 实际渲染对照

下表来自完整场景运行（可用 `--full-scene` 重现）。日常功能回归默认只绘制实际歌词场景，避免正在运行的播放器和无关封面、背景 GPU 工作影响测试；仍使用生产着色器、纹理和播放循环。

`tests/lyric-edit-electron-smoke.js` 加载生产渲染代码、解码 WAV 并维持播放，使用三行歌词、多行译文、4× 纹理、发光与故障效果。先连续输入，再按住滑轨停止输入 900 毫秒。基线通过 `--baseline-ref=5cf43bf` 加载 Git 中不可变的原始页面和模块。

| 测量 | 基线 | 修复后 |
| --- | ---: | ---: |
| 按住期间歌词重建 | 1 | 0 |
| 高清纹理生成 | 4 | 0 |
| 配置保存 | 1 | 0 |
| 预览阶段纹理上传 | 22 | 0 |
| 场景绘制调用 P95 | 15 | 5 |

这里只列纯布局拖动的上传量；字形变化需要基础文字上传，仍受每帧一张的预算约束。

GPU framebuffer 对照确认轻量预览文字实际可见，不是只修改状态变量。单次运行中，字形调整松手后可见文字约 0.26 秒完成准备，可见装饰约 0.9–1.5 秒恢复；这些是测试场景的观测值，不是通用时限。

离屏 Electron 的 RAF 间隔受测试调度和 GPU 状态影响，重复运行有明显波动，不作为桌面实际 FPS 或流畅度的承诺。用户负责最终视觉和拖动手感验收。

## 数据与边界

- 连续调整后重启页面，字重、字间距、译文间距、4× 清晰度正确恢复；临时预览没有覆盖画质设置。
- 取消、失焦、键盘结束、再次拖动与切歌后，旧构建不重新出现。
- 单行与多行最小距离按实际边界计算；覆盖中文、英文、黑体、宋体、Serif、等宽字体及译文字号端点，共 16 组实际 Canvas 字形。
- 缺失译文不生成空白译文行；背景透明度与裁切不重载视频、不重新读取媒体 Blob。

## 更新重点

- **搜索更快更全**：各平台结果先到先显示，按账户顺序优先；新增歌手、专辑、歌单、用户分类，支持拼音首字母搜本机歌曲。
- **多路音频输出与麦克风混音**：播放声音可同时送到多个设备和虚拟声卡，可把麦克风人声与音乐混合后给语音软件。
- **完整桌面模式可用滚轮**：播放器嵌在桌面时，鼠标滚轮可以直接在软件里滚动。
- **登录更顺**：QQ 音乐、网易云优先 App 扫码，扫码面板内嵌在软件里；可从浏览器导入登录，可拖线单独退出某个平台。
- **歌单架重做**：歌词稳定地停在歌单架旁并朝左侧转；左侧歌单与右侧歌单架同时只开一个；歌单架清晰度跟随画质。
- **播放与切歌更顺**：暂停、继续即时响应，切歌时歌名与歌词依次交接，拖动进度条长距离直达。
- **Aero 水光主题**：新增可选的水光玻璃主题，三种颜色与按压特效，默认关闭。
- **歌手详情与音质预设**：歌手页显示最新专辑并可展开全部；新增一键音质预设和分平台默认音质。

## 搜索

- 网易云、QQ、酷狗、汽水的结果谁先返回谁先显示，不再等最慢的平台；单个平台 8 秒超时只缺这一家。
- 排序按登录面板里的平台顺序优先，同一首歌在多个平台都有时只保留排在前面的平台；各平台结果会穿插显示，不再被某一家刷屏。
- 搜歌手名时优先显示歌手本人的歌，同名翻唱和上传不再挤到前面；带“深情版”等版本说明的歌排在原唱之后。
- 新增“综合 / 单曲 / 歌手 / 专辑 / 歌单 / 用户”标签：综合页在单曲上方显示最佳匹配的歌手和相关歌单；分类结果可继续向下加载。QQ 的歌单与用户、酷狗和汽水的分类搜索暂不支持。
- 晚到的结果平滑插入，正在看的行不会被顶走；中文输入法拼音阶段不触发搜索。
- 输入拼音首字母（如 `smfx`）可匹配本机已有的歌曲，只在本地比对。

## 播放、歌词与切歌

- 暂停 / 继续按下即生效，暂停后马上继续不再重置歌词；暂停淡出默认缩短，仍可在音量弹窗调整。
- 切歌时音乐立即播放，舞台先展示歌名再进入歌词，不再两套文字叠在一起；长前奏和纯音乐保持稳定标题。
- 按队列方向预先准备相邻歌曲的封面、标题和开头歌词，不降低所选画质。
- 点击或拖动进度条远距离跳转时，歌词快速滑到目标并停稳；开播时歌词不再先模糊后变清晰。
- 恢复上次进度时歌词从第一帧就对齐目标行。
- 播放地址网络失败会自动重试一次，仍失败时提供“重试 / 下一首”，重试保留原歌曲与进度。
- 封面加载更稳：新封面确认加载成功后再整体切换，失败自动重试并预热接下来两首的封面。
- 随机播放切回顺序播放时恢复原有顺序，当前歌曲和进度不变。

## 歌单架与界面

- 歌单架打开时歌词停在歌单架旁并朝左约 17° 侧转，不再随卡片晃动或离得很远；可在“歌单架”设置里调整歌词的左右、上下位置。
- 拖动画面后再打开歌单架，歌词直接飞向目标，不再先回正再折返。
- 左侧歌单面板与右侧歌单架同一时间只开一个；歌单架点击范围按卡片实际形状判断。
- 歌单架纹理按屏幕实际尺寸选择精度，高、超高画质下更清晰；暂停时展开、收起歌单架同样流畅。
- 视觉控制台再次点按钮或点击别处即可收起；按钮组恢复小标题，只属于某款视觉的设置会提示所属视觉并可一键切换。
- 背景卡片图标重绘为统一的线性图标；背景切换时保留设置的底色，不会突然透出桌面。
- 新增可选的 Aero 水光主题（界面 → 玻璃与左栏）。
- 新手引导补充视觉预设、背景媒体、歌单架和连线登录的介绍。

## 登录与账号

- QQ 音乐优先使用 QQ 音乐 App 扫码，网易云优先 App 扫码，均保留网页登录；网易云、QQ、酷狗的二维码直接显示在软件里。
- 修复 QQ 音乐 App 扫码后电脑端登录失败（含微信 / 手机号类账号的 50006 错误）。
- 酷狗扫码改用客户端授权，可以读取云歌单；需要官方安全验证时提供验证入口。
- Cookie 导入新增“从浏览器导入”（网易云、QQ、酷狗）。Chrome 127 起的新加密无法读取时会如实提示改用 Firefox / Edge 或扫码。
- 在登录面板把连线从 MR 上拖开即可单独退出该平台，4 秒内可撤销；点已登录的平台卡片只选中，不再重复打开扫码。
- 账号在线状态会定期向平台确认，平台明确拒绝时才显示断开；手动关闭的平台“展示”开关不会在重新登录后被自动打开。
- 酷狗、汽水、网易云歌单分页读取完整，读取中断时保留已加载的歌单并可重试。

## 歌手、音质与音源

- 歌手详情新增专辑区，预览最新 8 张，可在详情内展开全部并继续加载。
- 新增音质预设（系统 → 音质与输出）：省流 / 均衡 / 无损 / 最高，以及各平台的默认音质。汽水可选音质，选 320k 起播更快。
- 切换音源菜单会先确认候选是否真的能播放，并标出仅试听、需会员、需购买等情况。
- 汽水确认 VIP 但只能取得试听时，会明确说明原因。
- 移除 Spotify 的残留入口。

## 音频输出与麦克风混音

- 播放音频可同时输出到多个设备（最多 16 路），每路可单独设置音量、静音和 0–1000 ms 延迟补偿；设备离线后重连会尝试恢复。
- 可连接虚拟声卡（如 VB-CABLE），在语音或游戏软件里选择对应的录音端即可收到音乐。
- 新增麦克风混音：人声与音乐分别调音量，混合后输出到虚拟声卡，自己的主监听仍只听音乐；默认不开麦。缺少虚拟声卡时提供官方驱动下载入口。
- 修复 Windows 默认播放设备是虚拟声卡时，麦克风混音在切歌后自动停止的问题；连接长时间没有输出时会自动重建并给出提示。

## 完整桌面模式

- 鼠标滚轮可以在嵌入桌面的播放器里直接滚动；指向桌面图标或其他窗口时，滚轮仍交给它们，软件锁定时不接管。
- 面板空白处也可以按住左键上下拖动来滚动。
- 进入、退出完整桌面模式时任务栏图标的显示与恢复更稳定。

## 稳定性与资源

- 听歌统计、节拍缓存、Wallpaper Engine 静音包等缓存增加容量上限并自动清理，长期使用不会无限增长。
- 修正快速切歌、队列清空 / 重排、换账号期间的多种竞争问题；补齐弹窗和按钮的键盘操作。
- 网络请求增加总期限和响应体上限，取消或切歌时及时停止旧请求。

## 安装与升级

Windows x64。安装包名称为 `Mineradio-Remix-2.5.0-Setup.exe`，请对照同页 `SHA256SUMS.txt` 核对文件。已有 Remix 可直接覆盖安装，配置会保留；卸载保留用户配置与音乐。

安装包未数字签名，Windows 可能显示未知发布者或 SmartScreen 提示；SHA-256 用于核对文件完整性。

## 已知说明

- 把音乐或麦克风混音送给语音、游戏软件需要虚拟声卡（如 VB-CABLE）；普通耳机、音箱的多路输出不需要。不同硬件的延迟需要手动校准。
- 完整桌面模式的滚轮在多显示器、隐藏桌面图标等情况下仍需更多机器验证。
- 分类搜索暂不支持 QQ 歌单与用户、酷狗、汽水；平台能否播放完整版本仍取决于账号权益和平台授权。
- Wallpaper Engine 原生背景需要本机安装官方 Wallpaper Engine；键盘输入、部分网页滚轮和应用型壁纸仍不支持。
- `qishui-audio-decryptor/` 与 `qishui-auth-v6/` 的分发授权依据仍未核实，本版本不代表已确认这些资源的分发许可。

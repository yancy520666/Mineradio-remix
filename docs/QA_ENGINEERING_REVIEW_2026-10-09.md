1. 原 Node 服务 + 完整原浏览器前端：真实 HTML/CSS、131 项脚本、软件 WebGL、真实 HTMLAudioElement；隔离账号且平台响应是假空态，不是 Windows 主应用或官方平台成功证明。详见 [浏览器运行证据](qa/browser-runtime-2026-10-09/README.md)。

3. 隔离生产模块与 loopback：实际 Node 网络、磁盘和应用函数，模拟平台响应；不是实际账号或 CDN 成功证明。

5. 静态审查/官方公告：证明实现边界或受影响版本，不代表真实利用已发生。
6. 未验证/受阻：必须单列；没有证据的行不标通过。

## 已知验证边界和风险

- Electron 主入口及 `npm run test:electron` 在本执行环境的 Chromium Unix socket 处遇到 EPERM；修改前基线同样受阻。独立 Node 浏览器模式已实际运行完整原前端，但不能替代这一项。没有关闭生产锁或更改产品安全配置来绕过。
- 浏览器模式仍记录 Electron 内部 sandbox_bundle 的 Invalid URL 异常；空 HTML 对照未复现，根因尚未确认，不能宣称控制台无错误。
- 真实音乐平台的账号登录、会员权益、验证码、CDN网络速度和长期真实播放未验证；网络问题、平台回应与客户端实现缺陷分别记录。
- Windows 桌面、任务栏、全屏/滚轮、DWM/Wallpaper Engine、物理音频输入输出、虚拟声卡和实际安装/升级未验证。
- 桌面安全分支执行被工具安全检查中断。已有发现保留，相关 MFA 来源限制、原版凭据导入、请求体生命周期及依赖升级尚未修复；没有重试被拦操作或换工具绕过。
- 汽水相关资源的分发授权未核实，不因代码运行或测试通过声称合规。
- 用户导入的背景视频不是可随意删除的临时缓存；历史资源清理策略尚未确定，不自动删除用户媒体。
- CueField 非默认 synthetic bridge 仍有 96秒计划与64秒运行容量不一致。当前未接默认UI/server；没有擅自缩短小节数改变策略，不能列为已修。
- 键盘seek、3D/部分元信息非指针入口与真实读屏未完成；已补主要模态/标题/开关交互不等于全站可访问性合格。

原始DOM快照采用逐字节验证的gzip归档，映射与未压缩SHA见浏览器证据目录；历史原始日志保留其空白和失败输出，未为格式检查改写。源码与报告的差异空白检查单独通过，原始日志不冒称格式全净。

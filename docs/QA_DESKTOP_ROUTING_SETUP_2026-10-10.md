- 已安装设备的一键启用：只有明确启用手势才能申请短期 setup 授权；同 token 经设备枚举转为单次 capture，期限不延长。保存的有效选择优先；否则可确认的默认/唯一实体麦克风及唯一安全虚拟输出才自动选择。有歧义时要求选一次，不能为了“一键”猜设备或临时采集默认麦克风。
- 首次设置：打开路由且完整枚举中没有虚拟输出时，显示简洁提示卡。权限不足不当成没装驱动；暂不安装、关窗、过期请求、重复刷新不会反复弹卡。混音区保留下载驱动入口，与提示卡共用安装流程。

## 产品边界

软件内部把音乐与人声混合后送入虚拟音频的播放端，游戏选择对应录音端。实体麦克风不是可写入音乐的输出端。没有虚拟驱动时不能承诺通用游戏麦克风输入；不需要购买硬件声卡。

上下两区不是重复音频实例：上区管理音乐分发及每路输出，混音启用时对应目标由下区接管，普通音乐镜像排除该目标。当前音乐分支位于播放器主增益之后，因此主音量仍影响送往游戏的音乐；并非完全独立的监听增益架构。

## 安装安全与验收边界

仅使用基础 VB-CABLE 的官方 Pack45；不包含 A+B/C+D，不把驱动二进制装入源码包。固定下载来源、字节数、ZIP 与每文件 SHA256，限制解压布局和资源预算；Windows 启动前必须验证 Authenticode 为 Valid 且发布者证书符合固定指纹。官方同名包更新造成 hash 不同必须拒绝，不能自动放宽校验。

用户先看到第三方来源、Donationware、许可与捐赠入口，以及管理员授权、重启电脑、Windows 可能改变默认声音设备的说明。打开可见官方安装器，不传未经核实的静默参数，不自动重启或主动修改默认设备。安装器启动或退出不代表驱动已可用；重启并重新枚举后确认。进入 UAC/官方安装器交接后不承诺能自动撤回安装。

官网公开许可给出保留来源、Donationware 和捐赠机会的条件授权；原包 readme 另写集成安装过程需 Author agreement。保留官方完整内容，不声称已取得独立书面授权。未来商业/机构分发仍需核对适用条件。

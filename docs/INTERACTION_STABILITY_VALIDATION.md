# 启动、歌单交互与进度保护验证

日期：2026-10-02。使用源码和临时独立配置；没有生成安装包或更新 Release/Draft。

## 实现

- 启动文字、背景与声音同步压缩至约 1.5 秒；窗口实际显示后启动，完整 logo 后允许进入。
- 回到歌单顶部使用 300–500 毫秒减速动画。沿用详情与左栏共用的滚动轴，以虚拟目录索引定位，再根据实际控件和卡片边界校正。
- 歌单架封面预热、可见项优先、最多四个并发请求、12 秒超时和一次自动重试；重开或恢复网络后可再次请求。回调检查卡片身份和是否已销毁。
- 空播客和图片失败使用内置分类图标。没有查到可靠的官方默认图片接口，未引入猜测的第三方图片地址。
- 可见窗口不因失焦进入原生绘制节流；隐藏/最小化继续采用既有节流策略，桌面模式继续兼容。失焦触发有上限的重绘，不调用抢焦点或改变层级操作。
- 播放检查点保存在独立配置目录的 `playback-checkpoint.json`，约每 2.5 秒提交。切歌、暂停、手动跳转和正常退出立即提交；使用媒体事件更新，独立于动画帧。
- 磁盘采用串行写入、临时文件、fsync、替换和上一份有效备份；失败保留原数据。浏览器快照兼容保留，恢复时选最新有效来源。
- 超过 120 首的队列保留当前歌曲附近的窗口；媒体身份不匹配时不保存。续播等待元数据，避免加载初期的零进度覆盖续播位置。

## 实际结果

| 检查 | 结果 |
| --- | --- |
| 两次真实 Electron 启动 | 首次显示 453 / 405 毫秒；logo 动画完成时为 1500 毫秒，文字不透明度 1 |
| 800 个歌单的展开详情返回顶部 | 两种面板宽度下，卡片与顶部工具栏约 9.6 像素间隙；仅挂载 15 个卡片 |
| 队列按钮 | SVG 与按钮中心偏差横向、纵向均为 0 像素 |
| 空播客分类 | 两个分类均显示内置 SVG 封面 |
| 模拟慢网封面 | 人为设置 250 毫秒响应等待和 25 毫秒分块间隔；冷缓存约 287.5 毫秒，重复读取约 0.1 毫秒 |
| 网络与本地开销 | 请求等待约 255.9 毫秒、下载约 30.4 毫秒、卡片绘制约 0.4 毫秒、纹理提交约 0.2 毫秒 |
| 请求数量 | 同一封面重复读取只产生一次网络请求；八张图片的最高并发为 4 |
| 500 首队列检查点 | 当前第 351 首正确保存，队列窗口 120 首，进度 37.25 秒；绕过退出处理后第二次启动仍读到相同歌曲和进度 |
| 强制结束进程 | 等待落盘确认后强制结束独立子进程，重建存储后歌曲与 64 秒进度一致 |
| 损坏及写入失败 | 主文件损坏或残留临时文件回退备份；ENOSPC 模拟保留最后有效数据；旧提交不覆盖新提交 |

慢网结果来自可重复的本地网络夹具，不代表用户当时的真实网速；纹理提交耗时是 CPU 调用耗时，不代表 GPU 完成时间。

## 限制与交付边界

- 没有长时间复现用户报告的整窗偶发透明；验证了可见失焦时原生节流关闭，体验由用户复测。
- 不进行实际断电或强制关机。突然断电恢复最近完成落盘的检查点，不能承诺零秒损失。
- 测试首次出现端口竞争，错误日志来自隔离测试。独立 QA 配置改用各进程的测试端口范围，日常运行继续沿用原有端口选择。
- 检查命令：`npm test`、`npm run check`、`node tests/startup-flow-electron-smoke.js`、`node tests/playlist-interaction-electron-smoke.js`。后两项使用隔离配置；体验验收留给用户。

# 四项视觉开关定向验证

日期：2026-10-02，基准 `ce3e3ce`。范围仅歌词光粒、电影镜头、粒子溢光、轮廓高亮。

## 结论与修复

- 单句歌词光粒原先要求歌词溢光总开关开启才有亮度。现在独立读取光粒开关和已有强度值；不改用户强度、不强行开启歌词溢光。
- 电影镜头控制主场景相机，不控制音域回响 iframe 的相机。强度为零时无镜头效果；歌词镜头绑定也会影响感知。
- 粒子溢光控制封面粒子及部分骷髅材质，不控制音域回响。音域回响下禁用该开关与滑轨，保留已保存的偏好。
- 轮廓高亮使用封面边缘纹理，不是歌词描边；音域回响和骷髅不使用该封面路径，禁用并注明原因。自然封面纹理、黑色保护与预设都会影响可见幅度。
- 四项添加常驻作用范围说明；切换回适用背景恢复已有开关状态。

## 实际渲染验证

`tests/visual-effect-controls-electron-smoke.js` 在隔离 Electron 配置中加载实际页面与渲染器，通过真实按钮点击设置参数。固定几何、时间、信号和相机，用 WebGL 输出像素对比，而不是只检查配置或源码文本。未读取真实账号、未修改正在运行的播放器。

## 变异测试

只修改测试 HTTP 服务返回的内存副本，不改仓库文件：将边缘和溢光渲染值固定为零、使电影镜头始终走关闭分支、使光粒强度始终为零。四个变异分别触发对应像素输出断言失败，正常代码通过。未开展全项目变异测试或整套回归。

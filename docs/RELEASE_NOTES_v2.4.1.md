## 更新重点

- **音域回响性能优先**：新增可选性能开关，减少内置音域回响的网格、分辨率和部分特效，持续掉帧时提供提醒与自动降级。
- **Wallpaper Engine 导入与设置完善**：修复启动误判与连续切换卡住，网页壁纸可原生运行，软件内可编辑壁纸提供的配置。
- **首次使用引导重做**：八步介绍搜索、音质、评论、DIY 模式和壁纸导入，支持上一步与键盘操作。
- **壁纸异常可诊断重试**：绘制异常、停止绘制及上下文恢复失败时提供重试和诊断，减少后台切换产生的误报。

## 音域回响与性能

- 系统 › 性能与后台新增“音域回响性能优先”，默认关闭；内置 CmzYa Wallpaper Engine 版保持原始 320×320 网格及跟随屏幕的绘制节奏。
- 主动选择画质档位或开启性能优先后，WE 版按档位调整网格和渲染分辨率；低档关闭流星及点击流星效果，超高保留原始细节，不额外限制帧率。
- 地形版保留原有画质规则，开启性能优先后进一步减少网格和浮空方块数量。其他普通粒子背景尚未统一按档位减少粒子数量，外部原生 Wallpaper Engine 场景不受此开关控制。
- 前台帧率新增 30 FPS。掉帧判断以用户选定的帧率为目标，排除启动预热、后台、失焦与最小化时段。
- 关闭性能优先时，持续掉帧只提供建议，可选择“保持当前”；开启后临时降低质量，稳定后逐步恢复，不覆盖保存的画质档位。
- 绘制异常、持续停止绘制、初始化失败或 WebGL 恢复失败时可重试，保留所选壁纸。诊断显示当前渲染器信息，文字可选择复制。
- 首次启动仍为主播放器低画质、前台帧率跟随屏幕、性能优先关闭；已有用户恢复保存的配置。

## Wallpaper Engine 背景

- 修复 Windows 官方签名被误判、管理员桌面启动被拒绝及连续切换后一直加载的问题。
- Scene 保持原生画质，较大的项目允许更长冷启动；原生壁纸自动帧率上限为 60，手动固定帧率继续生效。
- 网页壁纸由本机官方 Wallpaper Engine 在独立窗口运行，“Perfect Wallpaper 完美壁纸”等不再固定显示静态安全预览。导入 HTML 不直接进入播放器渲染器，应用类项目仍只预览。
- 扩展图片与视频格式索引；视频解码失败时尝试官方原生播放，再退回带失败说明的预览。
- 壁纸卡片齿轮可编辑作者提供的文字、颜色、开关、数值、组合选项和文件等属性，支持搜索、保存与恢复。配置按项目私有保存，原壁纸文件保持只读。

## 首次使用引导

- 八步介绍搜索、音质标签、评论及楼中楼、DIY 模式、背景媒体与 Wallpaper Engine，右上角“?”可重新查看。
- 引导自动定位对应入口，提供上一步、键盘翻页和跳过，并尊重减少动态效果设置。
- 临时打开的 DIY 模式与控制台在退出对应步骤后恢复；用户亲手修改的 DIY 选择保留。

## 安装与升级

本版本为待发布草稿，提供 Windows x64 安装包 `Mineradio-Remix-2.4.1-Setup.exe`，可覆盖升级 2.4.0。安装前对照同页 `SHA256SUMS.txt` 核对文件；升级保留配置，正常卸载保留用户配置与音乐。

发布流程会执行源码、Electron 及安装 2.4.0 → 覆盖升级 2.4.1 → 启动与重启 → 卸载验证，通过后才生成草稿。安装包未数字签名，SHA-256 仅验证文件一致性。

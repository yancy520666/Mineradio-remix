# Windows 实机验收清单

用途：验证本轮代码修复在真实账号、音频设备、Intel 核显和 Windows 桌面环境中的效果。自动化测试通过不等于以下项目通过。GitHub 上传仍暂停；以最终交付的 Git 提交为准，不混用旧安装包。

## 测试前

- 先备份现有用户资料，保留能恢复的旧版本；不要覆盖唯一一份存档。
- 记录 Windows 版本、CPU 完整型号、核显型号、内存、分辨率和系统缩放比例。这里的 2K 测试采用 2560×1440。
- 使用相同歌曲、相同背景和窗口尺寸对比。先预热，再记录稳定状态；不要把一次 GC 波动当作泄漏或性能提升。
- 测试日志和截图请遮住账号标识。不要提供 Cookie、令牌、验证码、密码、请求正文或带鉴权参数的完整 URL。

## 1. 登录、安全验证与播放

- 网易云、QQ、酷狗、汽水分别检查网页登录、支持的扫码方式及已有 Cookie 导入入口；只使用自己有权使用的账号。
- 在等待扫码、手机确认、安全验证、登录完成等阶段分别取消或关窗；重新打开后不能串到旧请求，也不能假报成功。
- QQ 扫码说明只出现一次，标题和二维码对齐，窄窗口不遮挡按钮；加载、失败、二维码过期、验证提示仍能看到。
- 暂时断网时提示刷新登录状态，不能把网络失败直接说成账号过期，也不能静默删除已保存资料。
- 登录后实际播放一首可正常收听的歌曲，并检查自己有权限的会员歌曲。账号信息显示、获得 URL、实际出声是不同验收点。
- 汽水 MFA 隔离风险尚未完全关闭。若出现验证兼容问题，记录发生步骤与脱敏错误，不绕过浏览器安全提示，不提供验证码或 Cookie。

## 2. 播放、切歌与混音

- 连续快速切歌、暂停后立即恢复、长暂停后恢复，确认最终播放的是最后选择的歌曲，封面/歌词/进度一致。
- 分别听短曲、长曲、无节拍资料的歌曲；自动混音不能一开始就跳到短曲中部，也不能只播几秒便结束。
- 混音过程中拖动进度、手动切歌、改变音量和输出设备；确认没有重复实例、突然放大、串歌或无声卡死。
- 切换耳机/扬声器、拔出再接回设备，检查输出选择、正常回退及恢复。
- 本地导入歌曲从队列移除后，当前仍播放或分析的歌曲不能失效。已保存的浏览器 blob URL 跨重启仍有既有局限，不能当作可靠的本地媒体持久化方案。

## 3. 搜索

- 中文输入法拼音选字时按 Enter，不能先搜索未确认的拼音；确认文字后再 Enter 应正常搜索。
- 搜索过程中清空输入、按 Escape、点外部关闭、切平台/分类或进入用户歌单；旧结果不能覆盖新页面或自动重开弹窗。
- 网络失败与“确实没有结果”区分；分页失败后重试只补失败的部分，保留已成功结果，不能无限自动重试。
- 返回上一层后缓存仍可复用，点击和键盘操作均可用。

## 4. 画质与背景

- 1080p、2560×1440 分别检查低、中、高、最高档；可用时测试 100%、125%、150% 缩放。
- 最高档重点对比原版：封面粒子、发光、歌词、星尘、地形/流星、动画和跟拍不能因本轮无效工作消除而改变。它不是帧率保证。
- 高档允许轻微细节取舍；中低档允许更明显减载。检查细节稀疏、锯齿、闪烁和亮度是否可接受，不只看帧率。
- 来回切档及修改自定义分辨率/密度，再回最高档；用户设置不得被覆盖，不能持续增加几何体或显存占用。
- 星尘关闭再开启、歌词拖动/跳转、换行模式切换，验证重新出现时状态连续。
- 在 Sonic、普通背景、自定义图片、视频和 Wallpaper Engine 之间快速切换；失败的新背景应保留旧画面，不能闪黑或恢复已取消的背景。
- 最小化、隐藏、显示、恢复重复操作，音频不断；可见桌面壁纸不被误当作完全后台停掉。

## 5. 缓存与长期占用

- 连续播放/切歌至少覆盖多轮固定歌曲与多首新歌曲；分别观察主进程、renderer 和 GPU 进程，不只看面板里的单一数字。
- 记录预热后、30 分钟、60 分钟及更长运行时的内存和缓存目录大小。正常波动可接受，重点是同一测试循环是否持续净增长。
- 点击释放缓存：播放不能中断，账号、歌单、喜欢、用户设置、导入媒体及原始文件不被删除。
- 已有消费者的音频 Buffer 可能继续存活到使用结束；“解除缓存引用”不代表物理内存立即下降。
- Wallpaper loop 反复切换后旧闲置文件可淘汰，但正在播放的 URL 与分段读取不能变成 404。
- 歌词缓存写入失败应保留旧有效缓存。历史无法确定归属的临时文件不自动猜删。

## 6. 更新与重启

- 使用真实、可信且匹配平台的更新包测试下载、安装、重启；此项需用户操作，不是本地模拟测试结论。
- 检查重复点击重启不会启动多个安装器；关闭或取消安装、安装失败后能回到可用状态或再次尝试。
- 更新后确认版本、账号资料、歌单、设置和播放正常。没有实际完成安装不能标记为更新链路通过。

## 反馈格式

每个问题提供：版本/提交、硬件与分辨率、具体操作、预期/实际结果、能否稳定复现。性能反馈尽量附同一场景下修改前后帧率/帧时间与进程占用；截图或短录屏比“感觉有点卡”更容易定位。无需提供任何登录凭据。

## 7. 本轮追加：桌面拖动与麦克风混音

- 完整桌面且未锁定：在设置、队列、搜索或详情面板左侧空白内沿按住鼠标上下拖动；普通点击、歌曲长按排序、滑条与输入框不被抢走。退出桌面后原操作保持。此项为滚轮受限的拖动兜底，不代表原生滚轮已修复。
- 默认音质下方不再有说明小字，提示音滑杆上方显示“歌单架滚动音效”分割标题。检查窄面板和 125%/150% 缩放。
- 路由区状态与操作不矛盾，关闭混音不出现白色电平条。启用后只在运行时显示金色电平。
- 刷新麦克风、刷新输出、插拔设备和快速重复刷新，最新设备结果不被旧结果覆盖。未完整读取与真的无设备区分；输入选择和已有正常输出不被意外重置。
- 主动启用混音后关闭路由面板、最小化、进入游戏，混音继续；重新打开可停止。实际退出软件必须释放麦克风，重新启动默认不采集。
- 已安装虚拟设备且选择无歧义时，一次“启用混音”匹配实体麦克风和虚拟播放端；多候选需要选一次。游戏的录音输入仍由用户设为对应虚拟端（例如 CABLE Output）；播放器主监听设耳机，避免队友声音反馈。
- 未检测到虚拟输出时的卡片只有可靠设备结果才弹；“暂不安装”后同会话不反复打扰。可以从混音区的“下载驱动”再次进入。权限不完整不能误报没装驱动。
- 可选驱动测试会改变 Windows：先阅读官方许可和安装说明，再由用户决定。确认后校验官方包与签名并打开官方安装器；管理员授权、安装确认、重启电脑由用户完成。Windows 可能自动更改默认播放/录音设备，重启后检查并恢复自己需要的设置。
- 测试取消下载、网络失败、重复点击、取消 UAC、安装器异常。未知状态不能诱导重复启动；不应把安装器退出显示成“驱动已安装成功”。不为了通过测试关闭数字签名或系统安全检查。
- 官方包同名更新造成校验不符时，必须停止自动启动；通过明确的官方网页入口自行核查。

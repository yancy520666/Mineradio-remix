# Mineradio Remix 2.2.4

Windows x64 修复版本，基于原版 Mineradio 2.2.0 继续维护。

- 改善后台唤醒后的播放和歌词恢复，以及切歌时的音频图重建。
- 歌词滑轨拖动时保留清晰文字与实时布局，松手后分批恢复高级效果；译文最小间距按字形边界计算。
- 降低节奏分析保留的整曲 PCM 数据量。
- 修复内置音域回响背景和头像失败后的重试。
- 改善本地曲库的离线记录、文件身份识别与失效歌曲提示，接入系统媒体会话。
- 加固本机 API、媒体地址校验与凭据存储，关闭自动内存清理的提权请求。
- 图形后端由 Chromium 选择，兼容无法使用强制 D3D11 的环境。

请下载 `Mineradio-Remix-2.2.4-Setup.exe`，按同页 `SHA256SUMS.txt` 核对文件。已有 Remix 可覆盖安装；原版账号可通过软件内的导入入口迁移。

卸载保留用户配置及音乐文件。安装包当前未数字签名，Windows 可能显示未知发布者或 SmartScreen 提示。

本版本首先提供为发布草稿。字体、特效观感、拖动手感及长时间使用体验仍由用户验收；第三方音乐平台的账号、权限及网络可用性取决于平台与实际网络。

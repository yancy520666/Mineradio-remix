## 更新重点

- **评论区与楼中楼完善**：支持继续加载评论和回复，热门与普通评论分区显示；网易云、QQ、酷狗可切换最新／热门排序。
- **酷狗每日推荐接入**：读取完整每日推荐列表，点击歌曲即可播放整组推荐，未登录和读取失败时提供明确提示。
- **壁纸切换与跟随修复**：每张 Wallpaper Engine 壁纸独立保存缩放和位置，恢复圆角及文字配置同步，拖动窗口时及时跟随。
- **首页与启动更稳定**：修复悬停卡片移出框外、长歌名撑大卡片、亮色背景卡片间深色方底和启动闪白问题。

## 评论与推荐

- 网易云、QQ 音乐、酷狗、汽水音乐支持加载更多评论，保留已加载内容；重复内容自动去除，失败可重试，切歌或关闭详情后忽略旧请求。
- 热门评论和更多评论显示各自标题与数量；网易云、QQ、酷狗默认按最新排序，也可切换热门排序并继续翻页。
- 有回复的评论显示“N 条回复 ›”，点开后浏览楼中楼并继续加载。回复采用低一级的字号与亮度，展开入口和加载按钮沿用播放器主题色。
- 网易云与 QQ 使用带回复数量的新版评论接口，显示可获取的会员标识；网易云登录后可点赞或取消，其他平台显示点赞数。
- 没有回复的卡片更紧凑，往年评论显示年份；网易云经典表情显示为图片，新版贴纸暂以名称标签显示。
- 酷狗每日推荐保留完整歌曲列表、歌手、封面与音质信息，每次打开重新读取；点选歌曲后使用完整列表建立播放队列。

## Wallpaper Engine 背景

- 缩放和位置按壁纸分别保存，首次选择新壁纸使用默认取景，切回时恢复该壁纸的设置；旧当前壁纸设置自动保留。
- 原生壁纸按窗口和实时 DPI 恢复圆角，最大化／全屏退出后重新适配；WE 重置绘制区域时自动恢复。
- 同步当前 Windows 用户在 Wallpaper Engine 中保存的文字、颜色等属性，原项目文件保持只读。
- 原生壁纸改为响应窗口移动事件，跳过重复尺寸调整和图层配置，减少拖动时背景落后。
- 选择封面背景时退出原生壁纸层，避免壁纸残留或迟到回调重新显示。

## 首页、启动与更新

- 长中文歌名与连续英文名称不再撑大首页卡片，过长文字以省略号收尾。
- 首页快捷卡片悬停保持原位，保留玻璃明暗反馈；阴影收在圆角内部，亮色背景下卡片间隙不再出现深色方底。
- 启动画面保留到播放器完成绘制，避免页面切换时短暂闪白。
- 从源码运行时，更新弹窗也只显示更新重点的短标题。
- 正常卸载时清理已知的更新安装包缓存；覆盖升级时保留差量更新所需文件。

## 安装与升级

Windows x64 安装包。下载 `Mineradio-Remix-2.4.0-Setup.exe`，对照同页 `SHA256SUMS.txt` 核对文件。已有 2.3.1 可直接覆盖安装，或在软件内收到更新提示后直接升级；配置保留，卸载保留用户配置与音乐。

安装包经过发布流程的源码、运行时与安装／升级／重启／卸载验证。安装包未数字签名，Windows 可能显示未知发布者或 SmartScreen 提示；SHA-256 只核对文件完整性。

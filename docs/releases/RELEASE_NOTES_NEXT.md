# 下个版本

以下改动在源码中，尚未包含在已发布的 2.5.0 安装包里。

- 更新弹窗显示全部更新重点，长列表支持滚轮查看；从 2.5.0 升级到后续版本时生效。
- 歌手详情页支持滚动加载更多歌曲，网易云和 QQ 不再只显示首批 36 首；加载失败可点击重试。
- 歌单、歌曲、歌手、专辑详情支持关联跳转；详情卡片增加返回按钮，保留上一页已加载的列表和滚动位置，从歌单进入后可返回原处。
- 修复 Alt+Tab 切回播放器或从最小化恢复后，空格误触标题栏按钮、无法正常播放 / 暂停的问题。
- 修复左侧歌单展开时先闪现再播放入场动画，以及当前歌曲不在列表开头时下方可见卡片直接出现的问题。
- 修复鼠标移出左侧歌单后偶尔不自动收起的问题；保留常开设置和输入、键盘操作时的焦点保护。
- 右键展开歌单架后，拖动只旋转背景，歌词和歌单架保持固定，与详情页的操作方式一致；切歌刷新封面时也不会带动歌单架旋转。
- 修复确认账号登录失效后仍保留登录记录、下次启动重复提示的问题；清理同时覆盖保存的凭据与登录窗口缓存，保留临时断网和刚重新登录的会话。
- 修复在歌单架或详情页滚轮缩放、拖动背景后，退出时镜头距离或角度发生偏移的问题；保存并恢复打开前的距离、角度和回正锁定状态，歌词恢复原有布局。
- 调整滚轮缩放：主界面歌词与译文保持字号和大小比例，随镜头一起放大，不再自动缩小；歌单架仍按可用空间适配，修复打开时歌词被重复缩小的问题。实时边界适配仅用于歌词锁定视角时。
- 修复鼠标移出窗口、窗口失焦时误关闭已展开的歌单架或详情页的问题；拖拽经过左侧边缘也不会误触左栏、关闭歌单架。
- 修复左侧列表切回当前队列时，底部歌曲遗漏入场动画、突然出现的问题；先完成当前歌曲的滚动定位与虚拟列表更新，再统一播放可见行的入场动画。
- 优化启动后首页的衔接：开场期间提前加载、解码已知首屏封面，保持原有并发预算；首页内容在显示前完成准备，入口卡片分区入场，晚到的封面柔和淡入。减少首页重复渲染和登录检查结束后的重复推荐请求，保留快速跳过与减少动态效果的支持。
- 修复歌词背后的光晕在长歌词上被压扁、与文字对不齐的问题，光晕尺寸现在严格按文字纹理比例计算；展开歌单架的过渡期间，光晕与文字同步移动，不再滞后错位。
- 修复窗口从后台恢复后短时间内再次恢复播放时，歌词没有重新挂载、渲染循环没有唤醒的问题。
- 播放器各进程提高到“高于正常”优先级，电脑被编译、测试等任务占满 CPU 时，已缓存的歌曲不易卡顿；可用环境变量 `MINERADIO_DISABLE_PRIORITY_BOOST=1` 关闭。
- 调整首页进入动画：卡片区域改为缓入缓出的长渐显并依次错开，不再在约 0.1 秒内突然出现；搜索栏随之柔和淡入。

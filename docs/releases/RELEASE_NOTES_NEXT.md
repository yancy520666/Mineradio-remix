# 下个版本

以下改动在源码中，尚未包含在已发布的 2.6.0 安装包里。

- 修复点击 Home 返回首页后，入口卡片偶尔无法点击的问题，保留现有入场动画。

## 最新公开版本之后的改动

- 新增快捷键管理入口，可分别调整应用内与全局快捷键，清空停用、恢复默认，并提示重复或系统占用；保留现有默认按键，搜索 Tab、镜头和歌单架翻页也可自定义。清空“搜索与焦点切换”后，Tab / Shift+Tab 不再切换焦点；设置入口简化为单行和“管理”按钮。
- 修复单字歌词背后光晕偏方、叠成实心色块的问题，边缘更柔和，保留原有强度设置与纹理尺寸。
- 修复歌曲评论分类混排：网易云默认显示推荐，可切换最热和最新；QQ、酷狗的最新列表不再插入热门预览。QQ 的置顶与平台加权评论单独展示，分类切换和加载更多沿用各自的排序与分页。
- 搜索框右侧新增清空按钮，有文字时显示；一键清空输入和当前结果，保留搜索历史与输入焦点。
- 修正搜索栏悬停热区，按搜索框展开后的位置触发，移到窗口按钮或 DIY 开关时不再误展开；保留输入聚焦、结果列表和导入操作期间的显示。
- 歌词清晰度调整为省资源、均衡、高清、极致四档，保留已有选择，默认第二档。低档优先清晰重绘当前原文与译文，高档只缓存文字区域并限制纹理预算；新增字边抗锯齿，暂停换档也能直接生效。
- 修复清晰度优化中译文未适配裁剪纹理、导致异常放大和重叠的问题；四档清晰度保留原文与译文的尺寸、位置和间距，光晕、颜色与动画沿用原有设置。
- 修复歌词清晰度偶尔退回基础纹理的问题：按显示行数分配原有缓存预算，让屏幕内原文、译文优先于屏幕外预热；字体延迟加载及上下句高清开关变化后，暂停中的可见歌词也能完成所选档位的重绘。保留原有字号、间距、光效与动画。
- 顶部快捷键管理与使用引导按钮仅在 DIY 模式显示，退出 DIY 后隐藏且不占位。
- 新增“歌词自适应”（默认开启，歌词设置里可关）：回正视角、没有拖动画面时，过长的歌词与译文会作为一个整体平滑缩小，完整留在屏幕内，上下句不会比当前句更大；拖动、缩放画面、打开歌单架或开关该功能时，大小渐变过渡，不会突然跳动。保留“歌词镜头绑定”原有行为。左侧歌单栏打开到关闭的过程中歌词的适配比例保持不变，歌词不再随之缩放。优化左侧歌单栏、底部迷你队列和音质选项栏的玻璃质感（迷你队列与音质选项栏的底色跟随“面板不透明度”滑块）：底色更实，背后的发光歌词不再穿透干扰；歌单栏在玻璃浓度较低时会同步压暗背景，打开时歌词也会适度压暗，保留模糊、边缘高光和阴影。打开歌单架时，超长歌词的缩小下限由 50% 放宽到 30%，不再冲出屏幕左边。同时优化歌单架开合时歌词的动画：与镜头同步一次到位，不再冲过目标角度再回正，也不再先猛地上移；修复歌单架里长歌词切换到短歌词时整体偶尔瞬间飞出屏幕再回来的问题。歌单架取消固定时补上退场动画：卡片按收起时长淡出并滑出，歌词的开合进度跟随镜头的实际位置，与镜头、歌单架同步运动，不再瞬间消失。修复歌单架里换句时歌词没有上升滚动、只是一下子跳上去的问题；长歌词切到短歌词时，歌词会随之变近变大，当前句之外的长句单独限制宽度，并允许伸进歌单架或详情页一小段，保留半透明的层次感。
- 修复缩放或转动镜头后关闭歌单架时，歌词退场进度无法归零、仍停在缩小和侧转状态的问题；开合动画都以保存的视角为起止点（打开时也不再从中途起跳），关闭动画跟随实际返回视角，其他面板接管镜头时正常结束歌单架同步。
- 歌词光晕在所属句子不再是当前句、渐隐的过程中也跟随文字，不再因掉帧或后台返回后的瞬时重排而滞留在字形之外（后台返回后偶发的光晕错位未能在隔离环境复现，此处为防御性加固）。
- 修复译文行的光晕比背后文字大约 17% 的问题：同一句译文作为当前句和上下文句时文字大小不同，歌词行拼合时误用了另一种大小的光晕；现在按该行自己的文字重新生成光晕与深色衬底。

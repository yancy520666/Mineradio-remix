# Mineradio Remix 2.3.0

Windows x64 版本，基于原版 Mineradio 2.2.0 继续维护。2.3.0 在 2.2.4 的基础上带来汽水音乐完整版补全、崩溃后恢复播放进度、更快的启动动画，并集中修复播放、登录、本地曲库和数据安全方面的问题。

## 本版重点

- **汽水试听自动补全为完整版**：汽水音乐只给出 30–60 秒试听片段时（VIP 账号也会遇到），自动在你已登录的网易云、QQ、酷狗中查找同名、同歌手、时长一致的完整版本并改用它播放；找不到时照常播放汽水试听。首次播放不额外等待，同一首歌再次播放约 0.5 秒起播。
- **崩溃后恢复播放进度**：播放进度定期写入磁盘，异常退出后可回到最近一次保存的歌曲和位置。
- **启动更快、更顺**：logo 动画提速约 28%，约 2.5 秒完成，音效和背景光效保持同步；可以提前点击直接进入主界面。
- **扫码登录更可靠**：打开扫码面板即自动生成二维码并显示加载动画，不再出现空白卡片或“图片损坏”图标；网易云官方登录窗口等二维码就绪后再弹出，不再先显示一大片白屏。

## 播放与进度

- 歌曲开头加载失败或进度停滞时有限次重试，必要时刷新播放地址并提示；主动暂停后不会被自动续播，旧歌曲的任务不会影响新歌曲。
- 修复窗口切换打断暂停淡出后，空格和播放 / 暂停按钮可能一直失效的问题。
- 汽水 PC 播放接口无内容时尝试公开音源回退，按实际时长区分完整版和试听片段。
- 本地离线歌曲较多时不再在第 12 首就停止播放，会继续寻找后面可播放的歌曲。
- 音域回响背景的光效重新随音乐变化，新封面解码后即开始平滑换色。
- 系统时间被往回调后，播放进度仍能正常保存。

## 界面与交互

- 打开账户面板时默认显示左侧平台列表最上方的平台，跟随你自己的排序。
- 修复开启“控制条自动隐藏”后，鼠标移到音量（以及音质、歌词校准）弹窗还没拖动滑轨，控制条就先隐藏的问题。
- 修复首次双击快捷方式窗口未及时显示的问题；首次使用引导不再在正常重启后重复出现。
- 歌单回到顶部采用减速动画；修复长歌单展开与后续卡片重叠、内容穿过顶部透明工具栏的问题；歌单封面加载完成后立即刷新。
- 歌词光粒不再被“歌词溢光”总开关一起关闭；各项视觉效果注明作用范围，不适用的选项自动禁用并保留原设置。
- 统一队列入口、下一首播放、移除等按钮的图标与居中。

## 账号与登录

- 从本机原版 Mineradio 导入账号及视觉、听觉配置，只补齐缺失内容，保留 Remix 已有设置，不迁移播放和搜索历史。
- 修复扫码确认的结果在退出登录之后才返回时，把账号重新登录回来的问题。
- QQ、酷狗官方登录窗口在页面内容就绪后再显示。
- 账户面板开关和刷新时复用已加载的头像，减少闪烁。
- 网易云会员状态合并多个来源并校验套餐有效期。

## 本地曲库

- 修复歌曲移动位置后，旧位置被放入另一首歌并导入时，原歌曲被顶替、歌单播错歌的问题。
- 旧位置的文件被替换但未重新导入时，原歌曲显示为离线，而不是用原歌名播放别的文件。

## 性能与资源

- 在线音频暂停或预读足够时，内存中最多保留 16 MB 待播放数据，其余暂存到临时文件；暂停一首 100 MB 的无损歌曲时，相关内存峰值约从 95 MB 降至 16 MB。播放体验不变，临时文件会自动清理。
- 汽水加密音频的多个分段请求共用一次下载和解密，避免重复下载。
- 普通的窗口焦点切换不再重复刷新画面。

## 网络与安全

- 使用代理或加速器时，网易云、QQ、酷狗的已知媒体与封面域名通过 HTTPS DNS 获取真实地址，同时保留私网拦截；可设置环境变量 `MINERADIO_MUSIC_DOH=0` 关闭。
- 只有 C 盘的电脑也能使用节奏图磁盘缓存。
- Spotify 令牌改为与平台 Cookie 相同的系统加密保存，旧的明文令牌自动迁移。
- 卸载时不再沿目录联接删除安装目录以外的文件，并核对安装标记；本地封面拒绝通过链接读取缓存以外的文件。
- 凭据相关的错误日志不再包含凭据内容；自动更新拒绝晚到或版本不符的下载结果。
- 天气定位改用 HTTPS 并校验返回数据。

## 安装与升级

请下载 `Mineradio-Remix-2.3.0-Setup.exe`，并按同页 `SHA256SUMS.txt` 核对文件。已安装 2.2.4 的可直接覆盖安装，配置和账号会保留。本版安装包已在全新的 Windows 测试机上完成“安装 2.2.4 → 覆盖升级到 2.3.0 → 重启 → 卸载”的完整验证。

卸载只删除程序文件和快捷方式，保留用户配置与音乐文件。安装包当前未数字签名，Windows 可能显示未知发布者或 SmartScreen 提示；SHA-256 只能核对文件完整性，不能代替数字签名。

## 已知说明

- 汽水公开音源不保证 VIP 完整播放，片段长度由服务端决定；完整版补全需要你在网易云、QQ 或酷狗中至少有一个已登录且有播放权限的账号。
- 后台偶发透明画面的完整触发条件仍在排查，长时间闲置后的播放稳定性仍在观察。
- 字体观感、视觉流畅度和实体媒体键效果因设备而异，欢迎反馈。

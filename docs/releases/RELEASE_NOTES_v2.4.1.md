## 更新重点

- **壁纸双模式与交互**：保留原生实时效果，新增循环视频缓存；原生背景空白处可点击、拖动，软件内可修改项目配置。
- **画质与性能提示更稳**：首次画质按实际显卡选择，音域回响可选“流畅优先”；修复内置 WE 版绘制节奏与帧率恢复后的残留提示。
- **每日推荐与封面同步**：新增 QQ 音乐每日30首，推荐跟随平台顺序；修复加载中刷新和自定义封面不同步的问题。
- **引导与背景体验改进**：重做八步首次使用引导，封面背景加载高清图片，壁纸异常可重试并查看显卡诊断。

## Wallpaper Engine 背景

- 修复 Windows 官方签名被误判、管理员桌面启动被拒绝及连续切换后一直加载的问题。
- Scene 保持原生画质，较大的项目允许更长冷启动；原生壁纸自动帧率上限为 60，手动固定帧率继续生效。
- 网页壁纸由本机官方 Wallpaper Engine 在独立窗口运行，“Perfect Wallpaper 完美壁纸”等不再固定显示静态预览。导入的 HTML 不进入播放器自身的渲染器。
- 背景空白处的鼠标点击、拖动会转发给壁纸，按当前缩放与位置换算坐标；播放器控件、3D 歌单卡片和弹窗不受影响，点击网页壁纸也不会抢走播放器焦点。键盘输入与部分网页滚轮交互暂不支持。
- Windows 11 原生壁纸层采用系统圆角，减少四角突出；系统圆角半径不能完全匹配播放器自定义圆角，仍可能露出少量画面。Windows 10 暂无此能力；循环视频使用播放器自身的圆角裁剪。
- 移动、缩放窗口时背景同步跟随，减少旧画面拖影；壁纸本身卡顿时，跟随操作不会阻塞播放器窗口。
- 新增 APNG、OGV / OGG、WMV、MPG / MPEG 识别，GIF / APNG / WebP 预览保留动画；新增视频格式能否播放取决于本机 Wallpaper Engine 的解码支持。视频解码失败时尝试官方原生播放，再退回带说明的预览。
- 应用型（.exe）壁纸暂不支持运行，只显示项目预览，列表和点击提示会说明原因；缺少场景包、网页入口或视频文件时同样说明原因，没有预览图时保留当前背景。
- 壁纸卡片齿轮可编辑作者提供的文字、颜色、开关、数值、组合选项和文件等属性，支持搜索、保存与恢复。配置按项目单独保存，原壁纸文件保持只读。

### 原生实时 / 循环视频

- 界面设置的 Wallpaper Engine 导入选项下方新增两种播放方式，悬停或键盘聚焦可查看说明；默认保留“原生实时”，选择会保存。
- “循环视频”首次把 Scene / Web 的原生画面录制为约 20 秒、最高 1920×1080 / 30 FPS 的静音片段。后续复用本地视频，并关闭播放器自己的原生壁纸实例，减少持续渲染工作量；不会关闭桌面正在使用的 Wallpaper Engine 壁纸。
- 小窗口首次录制可选择“铺满屏幕录制”或“按当前窗口录制”；已有低清缓存可重新生成。临时全屏在录完、取消或失败后恢复原位置、尺寸与最大化状态，快速取消也会等待恢复完成。
- 录制中切换壁纸、切换模式、最小化或退出会取消本次任务；录制源中断或更换时丢弃半成品，避免保存最后一帧不动的假视频。失败后可重试或切回原生。
- 刷新壁纸库、重启或切回原生不会主动清空完整缓存；源文件或项目属性变化后重新生成。缓存总预算为 512 MB，新视频保存时会按创建时间清理较旧缓存；没有固定的每日到期时间。
- 循环视频没有实时音乐响应、鼠标交互、实时钟表或随机变化，衔接可能跳变；它减少原生渲染负担，但不保证每张壁纸都会启动更快或提高帧率。图片、直接视频和应用型项目继续沿用各自原有处理方式。

## 画质与音域回响

- 新安装首次启动时检测正在使用的显卡：独立显卡使用“超高”，保留原版全部细节；核显使用“中”，核显配高分辨率屏幕、软件渲染或低内存 / 低核心数电脑使用“低”。之后可在 系统 › 性能与后台 随时修改，已有用户保存的档位不受影响。
- 系统 › 性能与后台新增“音域回响流畅优先”，只作用于音域回响背景，默认关闭；全局画质仍由画质档位控制；内置 CmzYa Wallpaper Engine 版默认保持原始 320×320 网格及跟随屏幕的绘制节奏。
- 开启流畅优先后，WE 版按档位调整网格和渲染分辨率，低档关闭流星及点击流星效果；地形版进一步减少网格和浮空方块数量。外部原生 Wallpaper Engine 场景不受此开关控制。
- 前台帧率新增 30 FPS。掉帧判断以选定的帧率为目标，排除启动预热、后台、失焦与最小化时段。
- 关闭流畅优先时，持续掉帧只提供建议，可选择“保持当前”；开启后临时降低质量，稳定后逐步恢复，不覆盖保存的画质档位。
- 修复内置 WE 版音域回响在 demand 绘制模式下隔次刷新才画一帧的问题。帧率恢复后撤销性能建议，切换目标帧率时清除旧建议并忽略旧目标的报告；提示说明为“近期帧率低于目标”，不以肉眼观感替代测量。此次不调整流星检测、波纹或视觉参数。
- 绘制异常、持续停止绘制、初始化失败或 WebGL 恢复失败时可重试，保留所选壁纸。诊断显示当前渲染器信息，文字可选择复制。

## 推荐与平台顺序

- 登录面板左侧拖动平台顺序后，首页每日推荐入口、推荐弹窗的平台标签和歌单列表统一按这个顺序排列；推荐弹窗里仍可临时切换平台。
- 新增 QQ 音乐每日30首：登录 QQ 音乐后，推荐弹窗的 QQ 标签与首页每日推荐都读取账号当天的“每日30首”。
- 排在最前的平台当天没有可播放的推荐时，会询问是否改用其他已登录平台，也可勾选以后自动改用；不会用关键词搜索结果冒充推荐。
- 歌单按平台顺序合并，内置歌单在前；调整平台顺序时保留各平台内部的手动排序，之后仍可单独拖动歌单。
- 每日推荐加载中点击播放会等待当前请求，避免提前判为空列表；加载中刷新会在当前请求返回后再拉取一次，多次点击合并为一次刷新。切换账号或退出后，过期请求不会覆盖当前结果。
- 更换或取消歌曲自定义封面时，同步更新当前歌曲、队列与首页每日推荐，避免卡片继续显示旧封面。

## 首次使用引导与背景

- 八步介绍搜索、音质标签、评论及楼中楼、DIY 模式、背景媒体与 Wallpaper Engine，右上角“?”可重新查看。
- 引导自动定位对应入口，提供上一步、键盘翻页和跳过，并尊重减少动态效果设置；引导期间控制条和背景控制台保持可见，小窗口与全屏下高亮框不再错位。
- 还没有歌曲或未登录时，音质、评论和封面背景步骤会说明何时可用，引导可以完整走完。
- 临时打开的 DIY 模式与控制台在离开对应步骤后恢复；用户亲手修改的 DIY 选择保留。
- 封面背景从网易云、QQ 音乐、酷狗加载更高分辨率的封面，加载完成后才替换；失败或超时保留当前封面，快速切歌不会串图。原封面本身清晰度较低时无法补出细节。

## 安装与升级

Windows x64 安装包。下载 `Mineradio-Remix-2.4.1-Setup.exe`，对照同页 `SHA256SUMS.txt` 核对文件。已有 2.4.0 可直接覆盖安装，或在软件内收到更新提示后直接升级；配置保留，卸载保留用户配置与音乐。

安装包经过发布流程的源码、Electron 与安装 2.4.0 → 覆盖升级 2.4.1 → 启动与重启 → 卸载验证。安装包未数字签名，Windows 可能显示未知发布者或 SmartScreen 提示；SHA-256 只核对文件完整性。

## 已知说明

- 画质自动选择依据启动时实际使用的显卡；双显卡笔记本若由系统分配到核显，会按核显选择档位，可在 Windows 图形设置中为 Mineradio Remix 指定高性能显卡，或手动调高画质。尚未在核显真机上做长时间帧率验证。

- QQ 音乐每日30首已用真实账号只读验证可读取并播放；平台接口变化时会显示读取失败，不会替换为其他内容。
- `qishui-audio-decryptor/` 与 `qishui-auth-v6/` 的分发授权依据仍未核实，本版本不代表已确认这些资源的分发许可。

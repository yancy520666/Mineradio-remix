# 网络兼容与数据修复验证

日期：2026-10-02。源码修复；未生成安装包、未更新 Draft，未修改个人播放器配置。

## 修复范围

- `server-security.js` 仅对明确列出的网易云、QQ、酷狗媒体 / 封面域名处理 fake-IP。普通公网解析不增加 HTTPS DNS 请求；未知域名、IP 字面量、混有私网的解析结果继续拒绝。HTTPS DNS 的结果仍需通过原有公网检查，重定向也重新检查。
- `music-dns.js` 用阿里公共 DNS 的固定公网地址启动 HTTPS 连接，证书验证及 TLS 主机名保留为 `dns.alidns.com`，避免解析器域名本身被 fake-IP 影响。两地址有限回退、每次 2.5 秒总期限、64 KiB 响应上限、32 个在途查询上限、128 条缓存上限；CNAME 链和 A 记录的 TTL 共同限制缓存期限，最长 5 分钟。同域名在途查询合并，失败不缓存。
- 已将新模块加入安装包文件清单，避免源码可用而下次安装包缺少依赖。关闭环境变量为 `MINERADIO_MUSIC_DOH=0`，关闭后恢复原有严格拦截，不放行 fake-IP。
- C 盘可用时允许节奏图落盘；桌面版已有目录设置保留，独立服务使用用户目录。不存在的盘符及写入错误仍回退错误通知 / 内存路径。
- VIP 保留所有嵌套来源及 `vip_info_v2` 套餐来源，仅使用标准类型、明确标志及有效套餐；普通等级和文字标签不提升会员。套餐过期时间兼容秒 / 毫秒，非法时间不提升会员。
- 定位改用 `https://ipwho.is/`，适配坐标与时区字段，拒绝失败、空值及越界坐标；更新隐私说明，不新增自动定位触发。

## 定向验证

命令：`node --test tests/music-dns.test.js tests/network-compatibility.test.js tests/server-security.test.js`，15 项通过。未运行整套回归或 Electron 视觉验收。

| 场景 | 结果 |
| --- | --- |
| fake-IP、DoH 失败 / 私网回答、未知域名、危险重定向 | 恢复只使用校验后的公网地址；不放行私网，不丢失 Range；关闭开关有效 |
| DoH 去重、TTL 到期、CNAME、错误问题名及失败重试 | 合并并发查询，过期重新请求，异常回答拒绝，失败后可重试 |
| C 盘函数及真实隔离服务 HTTP 接口 | C 盘临时目录状态为 disk，写入成功，重新请求读回 `[0,1,2]`；模拟 EACCES 不改变上次有效内容 |
| VIP 空对象、后续来源、等级、标签、普通 VIP、有效 / 过期套餐 | 空来源不遮挡后续信息，不因等级或文字提升会员，普通 VIP 不变成 SVIP，过期及非法时间不生效 |

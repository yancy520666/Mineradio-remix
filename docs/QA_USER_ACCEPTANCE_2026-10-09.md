# 维护者实机验收清单（本轮未发布代码）

不要用旧安装包验收尚未合入的改动。先确认运行的源码提交与工程报告记录一致；本地提交不代表远端main或安装包已更新。优先用隔离测试配置和临时歌单，不覆盖日常配置，也不删除真实媒体。

## 必须补的 Windows / 平台路径

1. **冷启动与窗口**：首次启动、再次启动、最小化恢复、关闭再开；记录耗时与闪烁，观察应用图标。浏览器软件渲染结果不能代替此项。
2. **完整桌面模式**：进入/退出/重进，滚轮、点击、锁定/解锁、任务栏残留、铺满、多屏和125%/150%/200%缩放。原有滚轮、卡顿/全屏问题尚未闭环；不要仅凭代码修改判通过。
3. **各平台登录**：分别扫码、取消后重试、已登录时重新登录、退出、换账号；真实验证码由用户完成。验证关闭不等于验证成功；检查歌曲是否仍明确提示需验证。
4. **账号隔离**：慢加载期间从A换B，检查首页、目录、喜欢/收藏、评论和会员信息不残留A内容；重新打开页面确认。不要用真实破坏性写操作测试竞态。
5. **播放可靠性**：单曲完整播放、快速连切、暂停/恢复、拖进度、音质切换、音源不可用、断网重连、前后台切换；确认UI标题、封面、歌词、currentSrc和声音属于同一首。
6. **队列恢复**：临时混合本地/在线队列，随机→循环，插队/重排/删除，重启恢复；当前曲与进度不意外改变，清空确认后旧音频不继续且重启不复活。
7. **大型临时歌单**：加载多页后删一项、双击同一删除、加载尾页时换歌单；总数与尾页一致，不误删相邻条目。
8. **评论/封面**：冷打开、15秒内重开、切排序/切歌/关窗、回复翻页、离线后恢复；记录同设备同网络的TTFB/下载/解码/首屏时间。受控20ms假上游不是官方客户端对比。
9. **音频路由/混音**：主监听、附加输出、断开重连、路由拖动/取消、音量/延迟保存；明确授权后测试实体麦克风+音乐混到已有虚拟设备，并在游戏/语音软件选择其录音端。实体麦克风本身不是可写播放端。
10. **歌词**：播放中/暂停中校准，字重/间距/字体切换，逐字高亮；检查最终选定玻璃/发光样式恢复，非只有临时文字。多行、长行、译文、重启保存字体分别试。
11. **原操作手感**：搜索/队列标题尺寸、截断、悬停、单击播放、长按排序；Tab/Space/Enter/Escape及焦点返回；不能因为新增键盘能力导致鼠标双触发或取消长按。
12. **视觉与存档**：原主题、左栏雾面/遮挡/透明、13预设、背景图/MP4、视觉JSON/短码恢复。对照修改前所选画质与动画，不只比较截图；未引用媒体清理没有自动执行。
13. **AutoMix**：真实不同节奏/时长、短曲/长前奏、歌词保护区、暂停/跳过过渡；检查无空音、截尾、串曲、重复实例。纯规划数学测试不能证明音乐听感。
14. **长时间资源**：循环切歌/开关面板/字体和路由重试，记录主进程、renderer、GPU及音频子进程，不把“主进程RSS”当应用总量；检查退出后摄像头/麦克风指示消失。
15. **发布门槛**：处理安全报告开放项和依赖升级兼容后，再做Windows安装/升级/卸载与签名/摘要/CI；不重发旧版本标签和资产。

每条记录：源码SHA、Windows版本/缩放/设备、操作步骤、期望/实际、日志时间、必要截图。出现复现问题先留证据，不把测试配置问题直接归因平台，也不把平台拒绝统一伪装为客户端故障。

# Mineradio Remix

基于 [XxHuberrr/Mineradio-paused](https://github.com/XxHuberrr/Mineradio-paused) 继续开发的独立改造版。

原项目目前已长期停更，Mineradio Remix 基于原作 **2.2.0** 版本继续修复和改进，主要目标是提升播放稳定性、本地曲库体验、更流畅的歌词表现以及 Windows 桌面端的日常使用体验。

Remix 由 [yancy520666](https://github.com/yancy520666) 维护。原版作者、源码来源及授权信息见下方 [来源、隐私与授权](#来源隐私与授权)。

## 项目简介

Mineradio 是一款 Windows 桌面音乐播放器，支持：

- 在线与本地音乐
- 歌词舞台
- 粒子视觉效果
- 3D 歌单架
- 桌面模式
- Windows 系统媒体控制

本仓库在原版功能基础上继续进行稳定性修复、体验优化和安全改进。

## 主要改进

以下为当前源码的改进汇总；部分新提交改动还未上传到安装包。最近一轮修复请在 [下个版本更新说明](./docs/RELEASE_NOTES_NEXT.md)查看，新修复内容将在下个版本更新时提供。

### 播放与窗口稳定性

- 改善长时间最小化、切换窗口以及系统唤醒后的画面恢复。
- 手动恢复播放前主动唤醒音频上下文，减少“界面显示播放但没有声音”的情况。
- 改善开启 AutoMix 功能后会导致第三首以后的歌曲无法播放问题
- 本地歌曲离线、地址失效或读取 / 解码失败时自动提示原因并尝试下一首。
- 连续失效歌曲会合并提示，最多连续尝试 12 首，之后停止播放并提醒用户。
- 图形兼容改善：取消强制 D3D11，由 Chromium 选择图形后端。
- 后台预览修复：后台保留最后一帧，恢复显示时无需等待焦点才补画，改善首次 Alt+Tab 切屏时显示空白画面问题。
- 修复暂停淡出被窗口恢复操作打断后，播放按钮和空格可能一直失效的问题。
- 切歌开头无进度或加载失败时进行有限重试，必要时重新加载媒体、刷新播放地址并提示；主动暂停和旧歌曲任务不会触发自动续播。
- 汽水 PC 播放接口返回空内容时，尝试公开 SEO 音源回退；按实际音频时长区分全曲与试听，提示片段长度，保留已验证的账号会员状态。公开音源不保证 VIP 全曲。
- 增加独立磁盘播放检查点，约每 2.5 秒保存，并在切歌、暂停、跳转和正常退出时提交。异常退出后恢复最近一次有效保存的歌曲与进度，不能保证断电时零秒损失。
- 检查点内容不变时跳过重复磁盘写入，保留正常进度保存频率和重要状态变化。

### 启动与歌单交互

- 改善双击快捷方式后窗口未及时显示、需要再次点击的问题。
- 启动 logo、背景和声音按原版时间线呈现，约 1.5 秒后允许进入；允许进入的时间不等于整段动画的时长。
- 持久保存已展示的首次使用引导状态，避免正常重启后反复提示。
- 回到歌单顶部采用开始快、结束减速的动画，避让固定标题和工具栏，修正停靠时再次校正位置导致的抖动。
- 修正长歌单展开区域与后续歌单卡片重叠，以及滚动内容穿过顶部透明工具栏的问题，保留虚拟列表。
- 歌单架封面采用有限并发、预加载与失败重试；加载完成主动更新卡片，无需再次移动鼠标或滚动。
- 播客缺少封面或加载失败时使用随程序附带的分类图标。
- 统一队列入口、下一首播放、移除等按钮的 SVG 与居中布局。
- 修正鼠标快速离开控制条或窗口时悬停状态残留的问题，失焦或隐藏时也会清理。
- 新建、重命名内置歌单使用应用内输入框；短码复制失败时选中完整文本供手动复制，避免 Electron 不支持原生输入弹窗的问题。

### 歌词体验

- DIY 歌词间距改为固定布局单位，不再因切歌、长句或纹理清晰度变化影响基础间距。
- 开启翻译时统一预留译文空间。
- 优化调整歌词效果时的卡顿问题：拖动歌词滑轨时使用清晰文字进行预览，并暂时降低高级装饰和高清处理开销。
- 松开滑轨后分批恢复视觉效果。
- 优化原文与译文的最小间距可调节范围。

### 本地曲库

- 保留离线歌曲记录，不再因为文件暂时不可用自动删除曲目。
- 新导入歌曲使用完整文件的流式 **SHA-256 内容指纹**。
- 可识别文件改名、移动以及相同文件副本，并尽可能保留原有曲目引用。
- 旧版曲库索引可以直接读取。

### 系统与账号体验

- 接入 Windows 系统媒体会话。
- 与 Windows 同步曲名、歌手、封面、播放状态和播放进度。
- 支持系统播放 / 暂停、切歌和进度跳转。
- 优化账号头像有时因加载失败显示平台占位图的情况，并自动进行有限次数重试。
- 网络恢复后可以重新尝试加载头像。
- 开关账户面板和刷新账号状态时复用头像，避免反复清空、重新请求及闪烁。
- 移除未登录状态下的“世界和平”解锁彩蛋，保留首次登录引导。
- 支持从登录面板导入本机原版账号及视觉、听觉配置，不迁移播放历史和搜索历史。
- Windows Remix 安装版通过本仓库检测更新，用户确认下载后可安装并重启；源码 / Dev 模式使用外部下载页。草稿版本不会自动推送。
- 网络兼容改善，音频和封面连接失败时，尝试其他已通过安全检查的 DNS 地址。
- 为网易云、QQ、酷狗的已知媒体及封面域名增加代理 IP 兼容：必要时使用 HTTPS DNS 获取真实公网地址，保留私网拦截、重定向校验及地址绑定。
- 网易云会员状态合并多个信息来源，不再把普通等级或标签文字当成会员类型，并校验套餐过期时间。

### 安全与隐私

- 本地 API 限制为本机同源请求。
- 媒体代理阻止私网地址及危险重定向。
- 桌面登录 Cookie 使用系统加密保护。
- 手势摄像头仅向本地主窗口提供短时的视频授权，不放行麦克风或外部页面。
- 自动内存清理不申请管理员提权；提权仅允许显式手动清理，旧版设置会迁移到安全默认值。
- 天气 IP 定位接口改用 HTTPS，校验坐标和失败响应。
- 切换账号或关闭页面时会取消旧头像的待重试任务。

### 工程与测试

- 增加后台唤醒回归测试。
- 增加 Electron 实际运行测试。
- 每次 Push / Pull Request 自动执行回归检查。
- 发布打包前必须通过测试。
- 优化节奏分析过程中的音频频段处理，并在取消或失败时及时释放源节点，降低大段 PCM 数据长期驻留造成的内存峰值。
- 修复内置 **“音域回响 · Wallpaper Engine”** 被嵌入策略拦截的问题。
- 兼容网易云头像 JPEG 类型别名。
- 节奏图磁盘缓存支持 C 盘；独立服务默认使用用户目录，桌面版保留已有缓存目录设置。

相关修复可参考 [播放与窗口恢复 PR #1](https://github.com/yancy520666/Mineradio-remix/pull/1)。

## 兼容性与已知说明

旧版曲库索引可以直接读取。

对于已经离线、同时没有内容指纹的旧记录，程序无法可靠判断原文件是否只是被移动或改名，因此需要重新导入可用文件。程序不会仅根据歌曲名称猜测并自动合并或删除记录。

新导入文件需要完整读取一次以计算 SHA-256，因此首次导入会增加一定磁盘读取时间。

真实歌曲在长时间闲置后的持续播放稳定性仍在观察中。

fake-IP 兼容仅适用于代码中明确列出的音乐 / 封面域名；HTTPS DNS 不可用时会报告失败，不放行私网地址。可设置环境变量 `MINERADIO_MUSIC_DOH=0` 关闭该兼容路径。当前网络修复的范围与验证结果见 [网络兼容验证](./docs/NETWORK_COMPATIBILITY_VALIDATION.md)，修复前的问题核对见 [外部建议记录](./docs/UPSTREAM_REVIEW_2026-10-02.md)。

后台偶发透明画面的完整触发条件仍未确认；已有恢复措施与定向检查不代表所有长期使用场景都已覆盖。

## 本地开发

### 环境要求

- Windows
- Node.js

首次在仓库根目录安装依赖：

```powershell
npm ci
```

推荐使用隔离开发环境：

```text
start-remix-dev.bat
```

开发版窗口标题为：

```text
Mineradio Remix Dev
```

用户数据单独保存在：

```text
%APPDATA%\Mineradio Remix Dev
```

因此可以与正式安装版本并行测试。

登录面板底部的 **“导入本机原版配置与账号”** 同样支持 Dev 版。

导入前会要求确认；导入过程只补齐缺失账号和默认视觉设置，不会覆盖现有 Remix 配置，也不会修改原版文件。

### 普通源码启动

也可以直接运行：

```powershell
npm ci
npm start
```

`npm start` 使用默认 Remix 名称及默认用户数据目录。

与已安装正式版同时测试时，建议使用 `start-remix-dev.bat`。

## 测试

运行完整源码检查：

```powershell
npm test
npm run check
npm run test:electron
```

其中：

- `npm test`：自动发现并运行全部 `*.test.js`
- `npm run check`：检查源码及运行规则
- `npm run test:electron`：使用隔离临时用户目录执行 Electron 运行测试

Electron 测试覆盖启动恢复、音频恢复、歌词间距、设置保存与读取、系统加密、媒体会话状态、Wallpaper Engine 内置画布加载以及头像重试等功能。

字体观感、视觉特效流畅度、Windows 媒体面板显示以及实体媒体键效果仍需要人工验收。

## 构建

构建 Windows 安装包：

```powershell
npm run build:win
```

# Mineradio Remix

![Platform](https://img.shields.io/badge/platform-Windows%20x64-0078D6)
![Version](https://img.shields.io/badge/version-2.4.2-8A2BE2)
![License](https://img.shields.io/badge/license-GPL--3.0--only-blue)

**Mineradio Remix** 是一款沉浸式 Windows 桌面音乐播放器，基于已停止维护的 [XxHuberrr/Mineradio-paused](https://github.com/XxHuberrr/Mineradio-paused) **2.2.0** 继续开发。

原版的歌词舞台、粒子视觉和 3D 歌单架保持不变；Remix 主要在播放稳定性、本地曲库、歌词表现、账号与网络兼容以及安全性方面持续修复和改进。

本仓库由 **[yancy520666](https://github.com/yancy520666)、Codex 和 Claude** 共同维护，其中 Codex、Claude 参与 AI 协作开发。原始代码来源与授权见 [来源、隐私与授权](#来源隐私与授权)。

当前版本为 **2.4.2**（2026-10-05 发布），提供 Windows x64 安装包。

1. 在本仓库 [最新 Release](https://github.com/yancy520666/Mineradio-remix/releases/latest) 页面下载 `Mineradio-Remix-2.4.2-Setup.exe`；
2. 对照同页 `SHA256SUMS.txt` 核对文件；
3. 运行安装。已有 Remix 可直接覆盖安装，配置会保留。

说明：

- 已安装 2.2.4 或更高版本的 Remix，也可以在软件内收到更新提示后直接升级。
- Remix 使用独立的名称、应用 ID 和用户目录，可以与原版共存。原版账号需要在登录面板中主动确认导入。
- 卸载只删除程序文件、快捷方式和软件内更新留下的安装包缓存，保留用户配置与音乐文件。
- 安装包**尚未数字签名**，Windows 可能提示“未知发布者”或 SmartScreen 警告。SHA-256 只能核对文件完整性，不能代替数字签名。

## 2.4.2 更新内容

2.4.2 主要改进画质默认值和音域回响自适应：新安装统一使用“超高”画质，旧版自动选择的档位升级后一次性恢复为“超高”；音域回响自适应默认开启，只在无法达到流畅标准或反复卡顿时调整细节。完整说明见 [2.4.2 更新说明](./docs/RELEASE_NOTES_v2.4.2.md)，技术细节见 [版本更新技术说明](./docs/RELEASE_NOTES_NEXT.md)。

- **默认保持原始画质**：新安装统一使用“超高”画质，旧版自动选择的档位升级后一次性恢复为“超高”。
- **自适应默认开启**：该功能将帮助音域回响背景在持续低帧或反复卡顿时自动调整细节，默认开启。
- **优化自适应功能**：开启后自动在无法达到最低流畅标准时降低画质来提高帧率，并找到合适的平衡点；降低细节无效时恢复原画质，减少反复切换。
- **选择记录更可靠**：手动画质、关闭自适应和升级记录保存在桌面配置，更换启动端口后仍保留。

### 画质与自适应

- 新安装默认“超高”画质，不再根据显卡自动选“中 / 低”。没有性能压力时，音域回响保持所选画质；“超高”使用原始细节和分辨率。
- 音域回响自适应默认开启，只影响音域回响背景。主动关闭或在旧版建议中选过“保持当前”的用户保持关闭，可在 系统 › 性能与后台 随时调整。
- 跟随屏幕时以 60 FPS 为流畅目标，屏幕低于 60 Hz 时按屏幕刷新率；固定前台帧率时按所选帧率。不会因为一帧慢或略低于目标就降档。
- 不以先前跑过的高帧率作为降档目标：240 Hz 屏上从 120 FPS 降到 80 FPS、且没有反复卡顿时，仍保持画质。实际绘制仍跟随屏幕，性能足够时可跑满刷新率；自适应不会自动限制帧率。
- 除平均帧率外，增加反复长帧检测，平均帧率达标但持续卡顿时也可调整。严重低帧约 7 秒、一般持续掉帧或反复卡顿约 11 秒确认，单次切歌或封面加载的顿挫不会单独触发。
- 稳定后先恢复四分之一档；失败只撤回这一步，下次尝试更小幅度，连续失败时逐步延长观察间隔。降低细节后流畅度没有改善，会撤回这次调整，并在相同负载下暂缓重试。
- 画质调整不改变前台帧率设置。地形版调整时保留现有动画、波纹和流星状态；WE 版逐步调整网格与绘制分辨率。

### 配置与提示

- 手动选档、关闭自适应、一次性升级恢复等记录保存在桌面用户配置，本地服务换端口后不会重复重置画质或重新打开开关。
- 性能提示卡显示在播放栏上方；展开性能设置时改为组内提示。普通场景使用核显或软件渲染时，仍提供一次性的“调到中画质”建议，由你决定是否调整。
- 屏幕刷新率优先使用系统上报值，避免帧间隔估算波动反复清空掉帧判断。

### 升级须知

- 可从 2.4.1 直接覆盖安装，或在软件内收到更新提示后升级，配置保留。
- 升级后，没有手动选档记录的旧版“低 / 中 / 高”画质会一次性恢复为“超高”。2.4.1 中记录过的手动选择保留；2.4.0 没有这项记录，当时手动选的档位也可能被恢复，需要在 系统 › 性能与后台 重新设置。
- 新默认值可能增加普通场景在低配机器上的负载，可按提示选择中画质。

- 为听歌统计、节拍缓存与壁纸静音副本补上容量清理，保留累计次数、时长和用户设置；修复连续 AutoMix 过渡遗留音频节点的问题。

- 修复网易云歌单完成后仍提示未同步、重试未接着加载的问题；刷新失败保留已载入歌单，同步进度以已显示/总数呈现（如 1/7），只保留重试按钮。暂停背景默认 60Hz，遵循更低的已保存帧率；歌单架与歌词避让、复位动画按界面节拍更新，保留原画质。

- 调整电影镜头等独立开关的布局：铺满整行、增加留白，说明文字可换行，状态圆点不再被挤扁。
- 修复开播歌词先模糊后变清晰：可见及即将出现的文字优先按原清晰度准备，整首歌的轻量预加载只用于快速滚动过渡；保留所选高清效果和进度跳转动画。

- **背景切换底色连续**：音域回响与其他背景切换时，持续保留用户设置的底色，避免淡入淡出空档突然透出桌面；保存的透明度和 Wallpaper Engine 原生显示方式保持有效。

- **初次歌词跳转与单击静音**：歌词返回后分帧准备整首轻量文字（普通设备预算 32MiB，低配置 16MiB，含画布及纹理估算）；标题交接复用该轨道，早期点击从原位置滚动，沿途轻量文字及时显示，目标再补原画质与特效。只提前上传附近文字，远处高清底图回收，切歌取消旧任务。喇叭单击静音／恢复原音量，悬停仍可调节音量。

- **登录与封面边界修复**：切换平台不会被旧登录回调关闭二维码，退登开始后撤销入口及时结束；失败的封面预加载可稍后重试。

以下改动仅在源码中，尚未包含在已发布的安装包里：

- **首次拖动和切歌交接**：拖动缺字时才短暂保留已有文字；点按进度条恢复原快速滚动，旧歌词不再固定停留；歌名介绍更利落，旧文字退场约 180 毫秒、歌名最少展示 450 毫秒、上滑退出约 220 毫秒，保留原清晰度与特效。
- **音域回响余波**：WE 版密集波动被替换时平滑退场，暂停／后台恢复不因时间跳变整批消失；原网格、颜色、波形和传播速度保持，最多额外四条短暂余波。

- **搜索结果更快出现**：各平台的结果一返回就显示，不再等最慢的平台；输入新词会取消旧搜索，拼音输入过程中不搜索，重复搜索走短时缓存。同一首歌在多个平台都有时，优先显示账户面板里排在最上面的平台。
- **综合搜索**：默认在歌曲列表上方显示最匹配的歌手和几张歌单 / 专辑（网易云与 QQ 合并）；单曲按账户面板的平台顺序排列，搜歌名时优先显示原唱，晚到的平台结果平滑插入。
- **搜歌手、专辑、歌单、用户**：搜索结果顶部可切换类型，点击直接打开歌手 / 专辑详情、播放歌单或查看用户的公开歌单（目前支持网易云，歌手和专辑也支持 QQ）。
- **搜索补缺与分页**：晚到或后续页面的同曲会原地更新为优先平台来源；综合区更新时保持正在看的歌曲位置，分类搜索支持继续加载。
- **播放暂停更干脆**：暂停 / 播放按钮点击即切换，暂停后马上播放歌词不再重置；切歌时不再重画旧歌词，歌词进出场更顺。
- **打开歌单架前自动回正**：拖动转过画面后再右键或打开左侧歌单，先把视角平滑转回正面再展开，不再错位；左侧歌单滑出时歌词与镜头按屏幕刷新率移动。
- **账号在线检测**：网易云在登录后每 5 分钟及窗口回到前台时向平台确认会话，QQ 音乐识别平台的“未登录”答复；两次确认失效后断开连线并提示重新登录，断网不会误判。
- **封面加载更稳**：封面中转加入缓存，同一张图只下载一次；切歌时新封面加载成功后再整体切换，失败会自动重试，并提前准备队列里下两首的封面。
- **切歌、拖动、跳转更顺**：音域回响切歌不再因读取封面颜色卡住，配色渐变更轻；切歌时新歌词等旧歌词大部分退场后再出现；点击进度条时歌词先快后慢精准停住，拖动时可见行沿用所选高质量并分帧补齐；在歌词换行时暂停，换行动画仍以全速走完。
- **连线登录**：把连线从 MR 上拖开即可单独退出该平台（4 秒内可撤销）；网易云、QQ、酷狗的二维码直接显示在登录面板里，取不到时自动改用官方窗口。
- **新手引导更完整**：新增视觉预设、可选 Aero 水光主题、侧栏 / 舞台歌单架的介绍，最后演示连线登录。新用户 Aero 默认关闭，可在引导里主动开启；右键教学临时进入歌曲画面，展示真实 3D 歌单架滑出，下一步收起并恢复原状态。未登录时用标注为演示的卡片，不播放歌曲或保存临时布局。
- **重开播放与网络恢复**：重新打开后歌词首屏对齐保存进度；无可用歌词时标题完整显色并缩短等待。临时连接失败有限重试，失败卡片可重试或下一首，断网时保留当前歌曲。
- **按钮与歌单卡片更整齐**：视觉控制台的开关与滑块行同高同对齐；歌单详情的载入数量移到标题旁，操作按钮统一成等高胶囊并铺满整行。
- **滚动封面更及时**：当前可见歌曲优先加载，沿滚动方向准备后续封面，清理过时预取并为新封面保留请求位置；缩略图按所选画布质量取尺寸，失败后过一段时间可重新尝试。
- **切歌标题与红心查询**：慢歌词到达后保留同一首歌已显示的标题，再切换到正式歌词，保留所选高质量；网易红心查询共享短期缓存与并发请求，遇到限流后暂停重试，不再输出上游 Cookie。
- **QQ 扫码登录与浏览器导入**：手机 QQ 音乐用微信或 QQ 号登录时，扫码授权不再被电脑端丢弃；Cookie 导入里新增“从浏览器导入”，确认后只读取本机 Edge／Chrome／Firefox 里该平台的登录，取代登录后导出 Cookie 到桌面的提示；酷狗要求安全验证时直接打开登录入口。

### 2.4.1

2.4.1 主要改进 Wallpaper Engine 背景：新增“循环视频”播放方式，原生壁纸可以直接点击、拖动，并能在软件内修改壁纸配置。同时按显卡自动选择首次画质，接入 QQ 音乐每日30首，并重做了首次使用引导。完整说明见 [2.4.1 更新说明](./docs/RELEASE_NOTES_v2.4.1.md)，技术细节见 [版本更新技术说明](./docs/RELEASE_NOTES_NEXT.md)。

#### Wallpaper Engine 背景

- **两种播放方式**：在 界面设置 › Wallpaper Engine 导入 下方选择。“原生实时”（默认）保留壁纸的全部实时效果；“循环视频”会把 Scene / 网页壁纸录成约 20 秒的本地视频（最高 1080p / 30 FPS）循环播放，之后不再实时渲染，减轻持续负担。桌面上正在使用的 Wallpaper Engine 壁纸不受影响。
- **录制更省心**：窗口较小时可选择“铺满屏幕录制”或“按当前窗口录制”，录完、取消或失败后窗口回到原来的位置和大小；录制中断不会留下静止不动的假视频，清晰度不够的缓存可以重新生成。缓存在重启后保留，总量不超过 512 MB。
- **可以点、可以拖**：原生壁纸背景的空白处支持鼠标点击和拖动，播放器按钮、歌单卡片和弹窗不受影响；键盘输入与部分网页滚轮暂不支持。
- **软件内修改壁纸配置**：壁纸卡片上的齿轮可调整作者提供的文字、颜色、开关、数值等属性，支持搜索、保存和恢复默认；原壁纸文件不会被改动。
- **更稳、更全**：修复官方签名误判、以管理员身份启动被拒和连续切换后一直加载的问题；网页壁纸改由本机 Wallpaper Engine 运行，不再只显示静态预览；移动、缩放窗口时背景跟随更及时；新增 APNG、OGV、WMV、MPG 等格式识别。应用型（.exe）壁纸仍只显示预览。

#### 画质与性能

- **首次画质按显卡选择**：新安装时，独立显卡默认“超高”，核显默认“中”，低配电脑默认“低”；已有用户的设置保持不变，可随时在 系统 › 性能与后台 修改。
- **音域回响“流畅优先”**：新开关，默认关闭，只影响音域回响背景。开启后在掉帧时临时降低细节、稳定后逐步恢复；关闭时只给出建议，可选择“保持当前”。前台帧率新增 30 FPS 档位。
- **绘制与提示修复**：修复内置 WE 版音域回响隔一次刷新才画一帧的问题；帧率恢复后性能建议会自动撤销；绘制异常时可重试，并可查看、复制显卡诊断信息。

#### 推荐、封面与引导

- **QQ 音乐每日30首**：登录 QQ 音乐后，首页与推荐弹窗读取当天的“每日30首”。
- **推荐跟随平台顺序**：首页推荐、推荐弹窗和歌单列表按登录面板中拖好的平台顺序排列；首选平台当天没有推荐时，可选择改用其他已登录平台。推荐还在加载时点击播放或刷新，会等结果返回，不再误报为空。
- **封面同步与高清背景**：更换或取消歌曲的自定义封面后，当前歌曲、队列和首页推荐同步更新；封面背景改用更高分辨率的图片，加载失败时保留当前封面。
- **重做首次使用引导**：八步介绍搜索、音质、评论、DIY 模式和壁纸导入，可后退、用键盘翻页或跳过，右上角“?”可随时重看；未登录、小窗口和全屏下都能正常走完。

#### 升级须知

- 可从 2.4.0 直接覆盖安装，或在软件内收到更新提示后升级，配置保留。
- “循环视频”没有实时音乐响应、鼠标交互和实时时钟，首尾衔接可能有跳变；它减轻渲染负担，但不保证每张壁纸都启动更快或帧率更高。

- 本地 API 仅接受本机同源请求；媒体代理拦截私网地址和危险重定向。
- 桌面登录 Cookie 使用系统加密保存。
- 手势摄像头只向本地主窗口提供短时视频授权，不放行麦克风或外部页面。
- 自动内存清理不再申请管理员权限，提权仅限用户显式手动清理。

</details>

---

## 已知限制

- 真实歌曲在长时间闲置后的持续播放稳定性仍在观察中。
- 后台偶发透明画面的完整触发条件尚未确认；现有恢复措施不代表所有长期使用场景都已覆盖。
- 字体观感、视觉流畅度、Windows 媒体面板和实体媒体键效果需要人工验收。
- 具体 Wallpaper Engine 场景壁纸的渲染负载、拖动手感和桌面恢复仍需在更多机器上验证；壁纸的键盘输入、部分网页滚轮交互和应用型壁纸尚未支持。
- 汽水账号的楼中楼回复、酷狗登录后的个性化每日推荐尚未经过真实账号验证。
- 已离线、又没有内容指纹的旧曲库记录，无法判断原文件是否只是移动或改名，需要重新导入；程序不会仅凭歌曲名称自动合并或删除记录。
- 新导入的文件需要完整读取一次以计算 SHA-256，首次导入会稍慢。
- 第三方音乐平台的账号权限、可播放范围和接口可用性取决于平台本身，可能随时变化。
- 汽水音乐目前因平台校验问题无法正常播放，可改用其他平台。
- 音域回响自适应在真实低配核显上的长期播放效果、调档瞬间的顿挫和动画观感仍需更多机器验证；自动调整不能保证所有硬件始终达到目标帧率。

## 从源码运行

### 环境要求

- Windows x64
- Node.js 22（与 CI 一致）

### 安装依赖

```powershell
npm ci
```

### 启动

推荐使用隔离的开发环境，可与已安装的正式版同时运行：

```text
start-remix-dev.bat
```

开发版窗口标题为 `Mineradio Remix Dev`，用户数据保存在 `%APPDATA%\Mineradio Remix Dev`。登录面板中的“导入本机原版配置与账号”同样可用；导入前会要求确认，只补齐缺失内容，不覆盖已有配置，也不修改原版文件。

启动脚本会先退出同一 Dev 配置目录下的旧实例，再启动脚本所在目录的源码，避免不同工作目录被单实例锁转回旧窗口。新版优先正常退出；旧版不支持退出请求或 18 秒后仍未退出时，只结束已核实为 Dev 的进程树，不关闭正式版或其他 Electron 程序。Dev 的配置、账号和曲库文件保留。开发源码已修复 Aero 样式的作用范围，并确保透明特效画布穿透鼠标，避免挡住按钮点击。

也可以直接启动（使用默认名称和用户目录）：

```powershell
npm start
```

### 测试

```powershell
npm test
npm run check
npm run test:electron
```

| 命令 | 内容 |
| --- | --- |
| `npm test` | 自动发现并运行全部 `*.test.js` 单元与行为测试 |
| `npm run check` | 源码与运行规则静态检查 |
| `npm run test:electron` | 使用临时用户目录的 Electron 实际运行测试，覆盖启动、后台恢复、歌词、设置、加密存储、媒体会话、音域回响画布等 |

每次 Push / Pull Request 会自动运行回归检查，打包发布前必须通过测试。

### 构建

```powershell
npm run build:win
```

发布流程见 [RELEASE.md](./RELEASE.md)。

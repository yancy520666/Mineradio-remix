# Mineradio Remix

![Platform](https://img.shields.io/badge/platform-Windows%20x64-0078D6)
![Version](https://img.shields.io/badge/version-2.4.1_Draft-8A2BE2)
![License](https://img.shields.io/badge/license-GPL--3.0--only-blue)

**Mineradio Remix** 是一款沉浸式 Windows 桌面音乐播放器，基于已停止维护的 [XxHuberrr/Mineradio-paused](https://github.com/XxHuberrr/Mineradio-paused) **2.2.0** 继续开发。

原版的歌词舞台、粒子视觉和 3D 歌单架保持不变；Remix 主要在播放稳定性、本地曲库、歌词表现、账号与网络兼容以及安全性方面持续修复和改进。

项目由 [yancy520666](https://github.com/yancy520666) 维护。原作者、源码来源与授权见 [来源、隐私与授权](#来源隐私与授权)。

## 下载与安装

当前版本为 **2.4.0**（2026-10-04 发布），提供 Windows x64 安装包。

1. 在本仓库 [最新 Release](https://github.com/yancy520666/Mineradio-remix/releases/latest) 页面下载 `Mineradio-Remix-2.4.0-Setup.exe`；
2. 对照同页 `SHA256SUMS.txt` 核对文件；
3. 运行安装。已有 Remix 可直接覆盖安装，配置会保留。

说明：

- 已安装 2.2.4 或更高版本的 Remix，也可以在软件内收到更新提示后直接升级。
- Remix 使用独立的名称、应用 ID 和用户目录，可以与原版共存。原版账号需要在登录面板中主动确认导入。
- 卸载只删除程序文件、快捷方式和软件内更新留下的安装包缓存，保留用户配置与音乐文件。
- 安装包**尚未数字签名**，Windows 可能提示“未知发布者”或 SmartScreen 警告。SHA-256 只能核对文件完整性，不能代替数字签名。

## 2.4.0 更新内容

2.4.0 完善了评论区，接入酷狗每日推荐，修复 Wallpaper Engine 背景的切换与跟随，并让首页和启动更稳定。完整说明见 [2.4.0 更新说明](./docs/RELEASE_NOTES_v2.4.0.md)，技术细节见 [版本更新技术说明](./docs/RELEASE_NOTES_NEXT.md)。

### 评论与推荐
- **加载更多评论**：网易云、QQ 音乐、酷狗、汽水音乐都能继续加载评论；热门评论与更多评论分区显示，重复内容自动去除，失败可重试。
- **最新 / 热门排序**：网易云、QQ 音乐、酷狗的评论可在两种排序间切换，每次打开默认最新。
- **楼中楼回复**：有回复的评论下方显示“N 条回复 ›”，点开即可浏览并继续加载；回复楼主时不再重复显示“回复 某某”。
- **点赞与会员标识**：点赞数和心形图标在每条评论右下角，网易云登录后可直接点赞或取消；昵称旁显示平台的会员等级标识。
- **更紧凑的评论卡片**：没有回复的评论不再在底部空出一行，往年的评论日期带上年份；网易云的 [爱心]、[大哭] 等表情显示为图片。
- **酷狗每日推荐**：读取真正的每日推荐，展示完整歌曲列表，点歌曲即播放整组推荐；未登录或读取失败时给出明确提示。

### Wallpaper Engine 背景
- **每张壁纸独立取景**：缩放和位置按壁纸分别保存，切换到另一张时不再继承上一张的设置，切回时恢复。
- **圆角与配置同步**：原生壁纸跟随窗口圆角，并同步 Wallpaper Engine 里保存的文字、颜色等属性；选择封面背景时退出原生壁纸层。
- **拖动窗口及时跟随**：壁纸响应窗口移动，减少拖动时背景落后的拖影。

### 首页、启动与更新
- **首页卡片更稳定**：长歌名不再撑大卡片；悬停时卡片保持原位；亮色背景下卡片间隙不再出现深色方底。
- **启动不再闪白**：启动画面保留到播放器界面画好为止。
- **更新弹窗更简洁**：从源码运行时，更新弹窗也只列出各项更新的标题。
- **卸载更干净**：卸载时一并删除软件内更新留下的安装包缓存（约 112 MB）；软件内升级时保留它，用于下次差量更新。

- **音域回响性能优先**：系统 › 性能与后台新增可选开关，降低壁纸细节换取流畅度，WE 版同时降低背景分辨率；默认画面保持原样，持续掉帧才提醒，关闭后恢复原设置。渲染中断时可重试并查看实际显卡诊断。

## 历史版本

### 2.3.1

<details>
<summary>展开 2.3.1 更新内容</summary>

2.3.1 是一次稳定性更新，修复 2.3.0 中连续提示可能卡死、删除队列歌曲后播放错位等问题，并改进控制条、歌单面板和更新弹窗。完整说明见 [2.3.1 更新说明](./docs/RELEASE_NOTES_v2.3.1.md)。

#### 播放与本地曲库
- **连续提示不再卡死**：修复短时间内连续出现多条换源／音质提示时，播放器可能卡死或崩溃的问题；最多保留最近 4 条提示。
- **队列移除**：删除当前歌曲会切到队列里的下一首，暂停时保持暂停；删除前面的歌曲不再导致播放位置错位或跳过下一首。删完最后一首会停止播放，重启也不会恢复已删除的歌曲。
- **本地曲库防串歌**：歌曲移动后，旧位置即使放入大小相同的另一首歌，也不会以原歌名播放；放回原曲后可以立即恢复。
- **汽水完整版匹配**：区分同一首歌的录音室版、Live 版等不同版本，复用缓存前重新核对时长。
- **播放进度保存**：修复系统时间回拨或主动暂停后，定期保存进度可能停止的问题。

#### 界面与交互
- **歌单 / 队列面板**：图钉、随机与清空按钮统一为图标按钮；“切换模式”显示当前模式并与底部控制栏同步；清空队列需再次点击确认；当前播放的歌曲带主题色竖线和音柱。
- **控制条自动隐藏开关**：简约模式下也能看到；图标为图钉，立正表示常显，倾斜表示自动隐藏。
- **音质标签**：简约模式下也在歌名旁显示，可直接切换音质；播放本地歌曲时自动隐藏。
- **启动与导航**：启动时保留上次选择的视觉预设；鼠标返回／前进侧键不再让播放器页面意外跳走。

#### 更新体验
- **更新弹窗**：直接显示新版本的更新重点、当前版本与安装包大小，并提供完整说明链接；按钮简化为“下载更新 / 稍后”。
- **更新按钮**：标题栏的新版本按钮与旁边按钮对齐，不再上下浮动。
- **更新后清理**：升级完成后自动删除已安装版本的下载包（约 112 MB），保留差量更新所需的文件。

### 2.3.0

<details>
<summary>展开 2.3.0 更新内容</summary>

完整说明见 [2.3.0 更新说明](./docs/RELEASE_NOTES_v2.3.0.md)。

#### 播放稳定性
- **切歌恢复**：歌曲开头加载失败或进度停滞时，有限次重试、必要时刷新播放地址并给出提示；主动暂停后不会被自动续播，旧歌曲的任务不会影响新歌曲。
- **暂停按钮失效**：修复窗口切换打断暂停淡出后，空格和播放 / 暂停按钮可能一直失效的问题。
- **崩溃后恢复进度**：新增磁盘播放检查点，约每 2.5 秒及切歌、暂停、跳转、退出时保存；异常退出后恢复到最近一次保存的歌曲和进度。内容不变时跳过重复写盘。
- **长离线队列**：已知离线的本地歌曲单独计数，最多扫描一轮，几十首离线记录后面的可播放歌曲不再被挡住；真正的读取 / 解码失败仍保留 12 首的防循环上限。
- **汽水音乐**：PC 播放接口返回空内容时，尝试公开音源回退，并按实际时长区分全曲与试听片段。公开音源不保证 VIP 全曲。
- **汽水试听自动补全**：汽水只给出试听片段时，自动在你已登录的网易云、QQ、酷狗中查找同名、同歌手、时长一致的完整版本并改用它播放；找不到时照常播放汽水试听。付费歌曲在请求汽水的同时就开始查找，首次播放不再额外等待；同一首歌 30 分钟内再次播放直接使用上次找到的版本（实测约 0.5–0.7 秒起播）。等待较久时显示进度提示，告诉你当前在做什么。

#### 资源占用
- **在线音频内存封顶**：播放器暂停或预读已够时，在线音频代理在内存中最多保留 16 MB 待播放数据，其余部分暂存到临时文件、按顺序续传；与音乐平台的下载方式保持不变，播放体验不变。模拟暂停一首 100 MB 的无损歌曲时，代理内存峰值约从 95 MB 降至 16 MB；长播客同样受益。临时文件在连接结束、退出及下次启动时清理。
- **汽水音频重复下载**：同一首歌的多个分段请求共用一次下载和解密，修正缓存占用的重复计算，并为单首下载设置 256 MB 上限。
- **焦点切换**：普通的窗口焦点切换不再重复刷新画面视口；真正从后台恢复时仍执行完整修复。

#### 界面与交互
- **音量弹窗**：修复开启“控制条自动隐藏”后，鼠标移到音量弹窗还没拖动滑轨，控制条就先隐藏的问题。音质、歌词校准弹窗同样适用；拖动滑轨移出弹窗时保持显示，松开后恢复正常。
- **控制条悬停**：鼠标快速离开控制条或窗口、窗口失焦时，及时清理残留的悬停状态。
- **启动**：改善双击快捷方式后窗口未及时显示的问题；启动动画恢复原版时间线，约 1.5 秒后可进入；首次使用引导不再在正常重启后重复出现。
- **歌单**：回到顶部采用减速动画；修复长歌单展开后与后续卡片重叠、内容穿过顶部透明工具栏的问题；封面有限并发预加载，加载完成后立即刷新卡片。
- **官方登录窗口**：网易云登录窗口等二维码出现后再弹出，不再先显示一大片空白；QQ、酷狗登录窗口在页面内容就绪后再显示。
- **启动动画**：logo 动画提速约 28%，约 2.5 秒完成，音效与背景光效同步；动画过程更顺滑。
- **提前进入**：启动画面可以提前点击直接进入主界面，不必等待“点击进入”出现。
- **账户面板**：点头像时默认打开左侧平台列表最上方的平台，跟随你的排序。
- **扫码登录**：打开汽水音乐扫码面板时自动生成二维码，生成期间显示加载动画，不再出现空白卡片或“图片损坏”图标；收起后再打开会继续检测扫码状态，过期则自动换新二维码。
- **按钮与图标**：统一队列入口、下一首播放、移除等按钮的图标和居中；新建 / 重命名歌单改用应用内输入框。
- **视觉设置**：歌词光粒不再被“歌词溢光”总开关一起关闭；各项效果注明作用范围，在不适用的背景下自动禁用对应选项，切换回来保留原设置。
- **音域回响**：修复光效不随音乐变化的问题；新封面解码后立即取色，800 毫秒平滑过渡。

#### 账号
- **退出后账号复活**：修复网易云、汽水扫码登录的确认结果在退出登录之后才返回时，把账号重新写回的问题。
- **原版导入**：补齐账号及视觉、听觉设置，保留 Remix 已有的调整，不迁移播放与搜索历史。
- **头像**：开关账户面板和刷新状态时复用已加载的头像，避免闪烁和重复请求。
- **会员识别**：网易云会员状态合并多个信息来源，并校验套餐过期时间。

#### 网络与兼容
- **代理 / 加速器环境**：网易云、QQ、酷狗的已知媒体与封面域名遇到代理软件返回的虚拟 IP 时，通过 HTTPS DNS 获取真实地址，同时保留私网拦截；可设置环境变量 `MINERADIO_MUSIC_DOH=0` 关闭。
- **只有 C 盘**：修复只有 C 盘时节奏图缓存被禁用的问题。
- **天气定位**：IP 定位接口改用 HTTPS，并校验返回数据。

#### 安全与数据保护
- **卸载**：卸载时不再沿目录联接删除外部文件，并校验安装标记中的应用 ID，避免误删安装目录以外的内容。
- **本地封面**：校验封面的真实路径，拒绝通过链接读取缓存目录以外的文件。
- **本地曲库不串歌**：移动过的歌曲不会被旧位置上的其他文件顶替，旧位置被替换时显示为离线而不是播错歌。
- **Spotify 令牌加密**：Spotify 令牌与平台 Cookie 一样使用系统加密保存，旧的明文令牌自动迁移。
- **播放进度**：系统时间被往回调后仍能正常保存播放进度。
- **日志脱敏**：凭据解密失败、Spotify 令牌文件损坏时，日志不再包含凭据片段。
- **自动更新**：拒绝晚到的、版本不符的更新事件和空下载结果，避免误进入“可安装”状态。
- **构建流程**：CI 固定 Action 版本，构建权限只读，发布草稿使用单独授权的任务。

### 2.2.4（相对原版的主要改进）

<details>
<summary>展开 2.2.4 更新内容</summary>

以下改进自 2.2.4 起提供，之后的版本同样包含。完整说明见 [2.2.4 更新说明](./docs/RELEASE_NOTES_v2.2.4.md)。

#### 播放与窗口
- 长时间最小化、切换窗口、系统唤醒后，播放与歌词能够正常恢复；切歌时重建音频连接，减少“界面在播放但没有声音”的情况。
- 修复开启 AutoMix 后第三首及之后的歌曲无法播放的问题。
- 后台省电时保留最后一帧画面，Alt+Tab 预览不再空白；窗口恢复显示时立即补画，不必等待获得焦点。
- 取消强制 D3D11，由 Chromium 选择图形后端，兼容更多显卡环境。
- 降低节奏分析期间保留的整曲音频数据量，取消或失败时及时释放。

#### 歌词
- 拖动歌词滑轨时以清晰文字实时预览，松手后分批恢复高级效果，减轻调整时的卡顿。
- 歌词间距使用固定布局单位，不再因切歌或长句而变化；开启翻译时统一预留译文空间，译文最小间距可调。

#### 本地曲库
- 文件暂时不可用时保留离线记录，不再自动删除曲目；失效歌曲会提示原因并跳到下一首。
- 新导入歌曲使用完整文件的 SHA-256 内容指纹，能识别改名、移动和重复副本，尽量保留原有引用；旧版曲库索引可直接读取。

#### 系统与账号
- 接入 Windows 系统媒体会话：同步曲名、歌手、封面和进度，支持系统播放 / 暂停、切歌和跳转。
- 账号头像加载失败时有限次自动重试，网络恢复后可重新加载。
- 修复内置“音域回响 · Wallpaper Engine”背景被嵌入策略拦截的问题。

#### 网络与安全
- 音频、封面连接失败时，在已通过安全检查的 DNS 地址之间切换，改善单个节点或 IPv6 路由失效时的连接。
- 本地 API 仅接受本机同源请求；媒体代理拦截私网地址和危险重定向。
- 桌面登录 Cookie 使用系统加密保存。
- 手势摄像头只向本地主窗口提供短时视频授权，不放行麦克风或外部页面。
- 自动内存清理不再申请管理员权限，提权仅限用户显式手动清理。

</details>

## 已知限制

- 真实歌曲在长时间闲置后的持续播放稳定性仍在观察中。
- 后台偶发透明画面的完整触发条件尚未确认；现有恢复措施不代表所有长期使用场景都已覆盖。
- 字体观感、视觉流畅度、Windows 媒体面板和实体媒体键效果需要人工验收。
- 具体 Wallpaper Engine 场景壁纸的渲染负载、拖动手感和桌面恢复仍需在更多机器上验证。
- 汽水账号的楼中楼回复、酷狗登录后的个性化每日推荐尚未经过真实账号验证。
- 已离线、又没有内容指纹的旧曲库记录，无法判断原文件是否只是移动或改名，需要重新导入；程序不会仅凭歌曲名称自动合并或删除记录。
- 新导入的文件需要完整读取一次以计算 SHA-256，首次导入会稍慢。
- 第三方音乐平台的账号权限、可播放范围和接口可用性取决于平台本身，可能随时变化。

## 从源码运行

### 环境要求

- Windows x64
- Node.js 22（与 CI 一致）

### 安装依赖

```powershell
npm ci
```

### 启动

推荐使用隔离的开发环境，可与已安装的正式版同时运行：

```text
start-remix-dev.bat
```

开发版窗口标题为 `Mineradio Remix Dev`，用户数据保存在 `%APPDATA%\Mineradio Remix Dev`。登录面板中的“导入本机原版配置与账号”同样可用；导入前会要求确认，只补齐缺失内容，不覆盖已有配置，也不修改原版文件。

也可以直接启动（使用默认名称和用户目录）：

```powershell
npm start
```

### 测试

```powershell
npm test
npm run check
npm run test:electron
```

| 命令 | 内容 |
| --- | --- |
| `npm test` | 自动发现并运行全部 `*.test.js` 单元与行为测试 |
| `npm run check` | 源码与运行规则静态检查 |
| `npm run test:electron` | 使用临时用户目录的 Electron 实际运行测试，覆盖启动、后台恢复、歌词、设置、加密存储、媒体会话、音域回响画布等 |

每次 Push / Pull Request 会自动运行回归检查，打包发布前必须通过测试。

### 构建

```powershell
npm run build:win
```

发布流程见 [RELEASE.md](./RELEASE.md)。

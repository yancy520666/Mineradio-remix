# Mineradio Remix

![Platform](https://img.shields.io/badge/platform-Windows%20x64-0078D6)
![Version](https://img.shields.io/badge/version-2.5.0-8A2BE2)

**一款把歌词、封面和音乐做成舞台的 Windows 桌面播放器。**

Mineradio Remix 基于已停止维护的 [XxHuberrr/Mineradio-paused](https://github.com/XxHuberrr/Mineradio-paused) **2.2.0** 继续开发。原版的歌词舞台、粒子视觉和 3D 歌单架完整保留；Remix 在这之上补齐了日常听歌真正需要的东西：**更稳的播放、更快更全的搜索、能用的评论区、多平台之间的自动接力、可以接进语音软件的音频路由，以及一整套数据安全保护。**

本仓库由 **[yancy520666](https://github.com/yancy520666)** 维护。

## 为什么选 Remix

### 🎧 播放不再“断”

原版在长时间挂机、最小化、系统唤醒或连续切歌后，容易出现“有声音没界面”、歌词停住、AutoMix 第三首放不出来等问题。Remix 逐一修复：

- **后台唤醒、切歌自动恢复**：切歌时重建音频连接；开头加载失败或进度停滞时有限次重试并刷新播放地址，网络失败自动给出“重试 / 下一首”选项。
- **崩溃重连也能接着听**：约每 2.5 秒以及切歌、暂停、退出时保存播放检查点，异常退出后回到原来的歌曲和进度。
- **优化动画效果**：优化切歌时的画面bug，拖动进度条远距离也能丝滑滚动并停稳。
- **启动后第一次播放不卡**：首页静止时提前准备好上次歌曲的歌词、字体和播放地址。

### 🔀 多平台自动接力

网易云、QQ 音乐、酷狗、汽水各有各的版权和会员限制。Remix 把它们当成一个曲库来用：

- **试听自动换完整版**：任何平台只给试听片段时，自动在你已登录的其他平台找同名、同歌手、时长一致的完整版本并直接播放。
- **一键切换音源**：切换前先确认目标平台能不能真正播放，提前标出“仅试听 / 需会员 / 需购买”。
- **按你的平台顺序**：搜索、推荐和歌单都按你在登录面板里拖好的平台顺序优先。
- **酷狗QQ更好用**：不登录也能放免费歌；扫码登录可读取云歌单；会员歌曲如实显示“需会员”并提供官方试听。

### 🔍 搜索快而全

- 各平台结果**先到先显示**，不再等最慢的平台；同一首歌在多个平台都有时只保留优先平台。
- 新增**歌手、专辑、歌单、用户**分类，综合页直接给出最匹配的歌手和歌单。
- 搜歌手名优先显示本人原唱；支持**拼音首字母**搜本机已有的歌曲。

### 💬 评论区真正可用

四个平台的评论都能**继续加载、楼中楼回复、最新 / 热门排序**；显示点赞数和会员标识，网易云登录后可直接点赞。

### 🎙️ 音频输出与麦克风混音

- 播放声音可**同时输出到多个设备**（最多 16 路），每路单独音量、静音和延迟补偿。
- 接上虚拟声卡（如 VB-CABLE）后，可以把**音乐和你的麦克风人声混合**后送进语音或游戏软件，自己耳机里仍只听音乐。

### 🖼️ 背景与桌面

- **Wallpaper Engine 原生壁纸**：直接用本机的 Wallpaper Engine 渲染，壁纸可点击、拖动，可在软件内修改壁纸属性；也可录成循环视频减轻负担。
- **完整桌面模式**：播放器嵌在桌面上时滚轮、拖动都能用，控制条可自动隐藏。
- **画质分档与自适应**：优化画质分档功能，超高保持原版观感；核显可选中、低档；音域回响背景卡顿时自动调整细节。

### 🔐 安全与数据保护

- 登录 Cookie 使用 Windows 系统加密保存；本地 API 只接受本机同源请求，媒体代理拦截私网地址和危险跳转。
- 卸载不会沿目录联接误删外部文件，也不会删除你的配置和音乐；本地曲库用内容指纹识别歌曲，移动、改名不串歌。
- 独立的名称、应用 ID 和用户目录，可与原版共存；原版账号和视觉配置可**只读导入**，不修改原版文件。

## 下载与安装

当前版本 **2.5.0**，Windows x64。

1. 在 [最新 Release](https://github.com/yancy520666/Mineradio-remix/releases/latest) 下载 `Mineradio-Remix-2.5.0-Setup.exe`；
2. 对照同页 `SHA256SUMS.txt` 核对文件；
3. 运行安装。已有 Remix 可直接覆盖安装，配置保留；2.2.4 及以上也可在软件内收到更新提示后直接升级。

- Remix 可以与原版共存。原版账号需要在登录面板中主动确认导入。
- 卸载只删除程序文件、快捷方式和更新缓存，保留用户配置与音乐文件。
- 安装包**尚未数字签名**，Windows 可能提示“未知发布者”或 SmartScreen 警告。SHA-256 只能核对文件完整性，不能代替数字签名。

## 2.5.0 更新内容

完整说明见 [2.5.0 更新说明](./docs/releases/RELEASE_NOTES_v2.5.0.md)。

- **搜索更快更全**：各平台结果先到先显示，按账户顺序优先；新增歌手、专辑、歌单、用户分类，支持拼音首字母搜索歌曲。
- **多路音频输出与麦克风混音**：播放声音可同时送到多个设备和虚拟声卡，可把麦克风人声与音乐混合后给语音软件。
- **完整桌面模式可用**：播放器嵌在桌面时，修复不能全屏问题，以及鼠标滚轮可以直接在软件里滚动。
- **优化客户端登录**：QQ 音乐、网易云、酷狗、汽水优先 App 扫码，修复扫码面板无法正常显示bug；可从浏览器导入登录数据，可拖线单独退出某个平台。
- **歌单架重做**：优化歌词翻转动画，更显丝滑优雅；优化操作逻辑，左侧歌单与右侧歌单架同时只开一个；提升歌单架清晰度上限，歌单架清晰度将跟随整体画质调整。
- **播放与切歌更顺**：暂停、继续即时响应，优化切歌动画，优化拖动进度条长距离直达过程中动效；启动后第一次点播放不再卡顿、歌词不再闪烁。
- **试听自动换完整版**：任何平台只给试听片段时，优先改用其他已登录平台的完整版本；酷狗，QQ不登录也能播放免费歌曲。
- **Aero 水光主题**：新增可选的水光玻璃主题，提供三种颜色与按压特效，默认关闭。
- **歌手详情与音质预设**：歌手页显示最新专辑并可展开全部；新增一键音质预设和分平台默认音质。
- **汽水音乐可以正常播放**：修复之前汽水音乐登录后无法正常播放问题。

## 更多改进

以下是历次版本中较小但实用的改动，完整内容见各版本说明。

<details>
<summary><b>播放与歌词</b></summary>

- 歌词间距固定，不再随切歌或长句变化；开启翻译时统一预留译文空间。
- 开播时歌词不再先模糊后变清晰；修复歌词光晕偶尔与文字错位。
- 随机播放切回顺序播放时恢复原有顺序；队列删除当前歌曲会接下一首，不再错位。
- 封面确认加载成功后再整体切换，失败自动重试，提前准备接下来两首的封面。
- 在线音频代理在内存中最多保留 16 MB 待播放数据，暂停长歌曲不再占用大量内存。
- 本地曲库文件暂时不可用时保留离线记录，不自动删除曲目。

</details>

<details>
<summary><b>界面与交互</b></summary>

- 视觉控制台分块整理、名称更直白；再次点按钮或点击别处即可收起。
- 左侧歌单栏可见歌曲依次入场；图钉、随机、清空统一为图标按钮，清空需二次确认。
- 音域回响背景切换淡入淡出更利落；新增 WE 主题“封面”“月白”。
- 启动画面可提前点击进入；启动不再闪白；更新弹窗直接列出更新重点。
- 首次使用引导覆盖搜索、音质、评论、DIY、壁纸、歌单架和连线登录，可随时用右上角“?”重看。
- 弹窗和按钮补齐键盘操作。

</details>

<details>
<summary><b>账号与推荐</b></summary>

- 修复 QQ 音乐 App 扫码后微信 / 手机号类账号登录失败（50006）。

<details>
<summary><b>网络、资源与安全</b></summary>

- 代理 / 加速器环境下，已知音乐域名遇到虚拟 IP 时通过 HTTPS DNS 获取真实地址。
- 音频、封面连接失败时在已校验的地址之间切换，改善单节点或 IPv6 失效时的连接。
- 听歌统计、节拍缓存、壁纸静音包等缓存有容量上限并自动清理。
- 网络请求有总期限和响应体上限，切歌时及时停止旧请求。
- 自动内存清理不再申请管理员权限；手势摄像头只向本地主窗口短时授权。

## 已知限制

- 第三方音乐平台的账号权限、可播放范围和接口可用性取决于平台本身，可能随时变化。没有任何平台会员时，会员歌曲只能播放官方试听。
- 当前版本已对汽水音乐登录和校验做出补丁，但仍可能因平台校验问题无法正常播放。
- 把音乐或麦克风混音送给语音、游戏软件需要虚拟声卡（如 VB-CABLE，该虚拟声卡已内置一键安装方式）；不同硬件的延迟需要手动校准。
- Wallpaper Engine 原生背景需要本机安装 Wallpaper Engine；键盘输入、部分网页滚轮和应用型壁纸尚不支持。
- 完整桌面模式的滚轮在多显示器、隐藏桌面图标等情况下仍需更多机器验证。
- 音域回响自适应不能保证所有硬件始终达到目标帧率。
- 字体观感、视觉流畅度、媒体键效果等仍可能因某些原因卡顿。
- 已离线、又没有内容指纹的旧曲库记录无法判断是否只是移动或改名，需要重新导入；新导入的文件需要完整读取一次以计算指纹。

## 从源码运行

### 环境要求

- Windows x64
- Node.js 22（与 CI 一致）

### 安装依赖

```powershell
npm ci
```

### 启动

推荐使用隔离的开发环境，可与已安装的正式版同时运行：

```text
start-remix-dev.bat
```

开发版窗口标题为 `Mineradio Remix Dev`，用户数据保存在 `%APPDATA%\Mineradio Remix Dev`。启动脚本会先退出同一 Dev 配置目录下的旧实例，不会关闭正式版或其他 Electron 程序，Dev 的配置、账号和曲库文件保留。

也可以直接启动（使用默认名称和用户目录）：

```powershell
npm start
```

### 更新 Git 源码工作副本

关闭此目录运行的源码版后，可双击项目根目录的 `update-mineradio.bat`。它只从本仓库的 `main` 快进更新；本地有改动、提交分叉或正在进行 Git 操作时会停止，不会强制覆盖。依赖变化时需另行运行 `npm ci`。不适用于没有 `.git` 的源码压缩包，也不会升级已安装的 EXE。

### 测试

```powershell
npm test
npm run check
npm run test:electron
```

| 命令 | 内容 |
| --- | --- |
| `npm test` | 自动发现并运行全部 `*.test.js` 单元与行为测试 |
| `npm run check` | 源码与运行规则静态检查 |
| `npm run test:electron` | 使用临时用户目录的 Electron 实际运行测试 |

每次 Push / Pull Request 会自动运行回归检查，打包发布前必须通过测试。

### 构建

```powershell
npm run build:win
```

发布流程见 [RELEASE.md](./RELEASE.md)。
